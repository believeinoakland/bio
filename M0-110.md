  otherwise read the working tree — the same code works before and after the cutover, and against plain test folders.
  A `BIO_COORD_REF` override lets controls plant into a local, unpushed commit. Forcing a reader back to the working
  tree is the negative control the row names.
- **New `plancheck` checks:** once `coord` exists, every moved path on `main` must be EXACTLY the pointer (a stale merge
  that restores content fails); any `origin/main:<moved path>` reference left in the tracked tree fails.
- **The migration script** builds `coord` as a ROOT commit with no parent (a later merge of `coord` into `main` is then
  refused as unrelated history), with FIXED dates so a re-run gives the same commit, taking its content from the
  integration HEAD (which carries neighbours' claim blocks merged in the same batch); it swaps each moved file for its
