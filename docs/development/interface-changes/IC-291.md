### The change, on the wire

- **New op, `actionrisktier`** — member class (`admin`, `member`, `probe` reach it), capability `contribute`,
  mutating, a session op in `ACTION_ACTIONS` so `author` and `viewer` are the SERVER's stamps. `target=<action id>`;
  `tier` (1, 2 or 3; the query string's `"2"` reads as 2) and `reason` (1-500 characters, no quote, backslash or
  line break) in the query or the POST body. On success: `{ ok, target, risk_tier, risk_tier_words, prior,
  prior_words, by, at, reason, risk_tier_history, weight: "single" }`. It writes `risk_tier` in the action's
  bytes, APPENDS `{tier, prior, by, at, reason}` to `risk_tier_history[]`, and records a Session Log entry.
  Refusals, in order: `MACHINE_CANNOT_SET_RISK_TIER` (C-32.19, first, whatever the payload); `NO_TARGET`,
  `NO_SUCH_BUNDLE`, `NOT_AN_ACTION`, `NO_DOCUMENT`; then `BAD_RISK_TIER`, `RISK_TIER_REASON_REFUSED`,
  `RISK_TIER_UNCHANGED`, `RISK_TIER_HISTORY_UNSPLICEABLE` (C-90.2-5). Published in `ACTS` ("Revise risk tier", on
  any action) and in `MACHINE_REFUSALS`, so a machine is not offered it.
- **Newly refused** (`{ ok: false, reason: "RISK_TIER_REWRITTEN", code, check: "C-90.1", translation, bundleId,
  held?, risk_tier, detail }`): an `op=promote` of an action, not a `replay`, by a MEMBER (a machine is answered
  C-32.19 first, as before) whose bytes state a `risk_tier` different from the version it replaces, or a
  `risk_tier_history` different from the one it holds; and a CREATION stating a non-empty `risk_tier_history`.
  **Before this change a member's plain revision from 3 to 1 landed, with no reason and no history.**
- **Unchanged:** a creation stating any tier (intake: UI-85, D-483); any revision carrying the tier and history
  forward unchanged — a member's, a machine's, and every splicing act in `store.mjs` (`actionmove`,
  `actioncorrespond`, `actionlaws`), which carry the front matter byte-for-byte; every C-32.19 outcome.
- **C-2.10 gains a chain arm**: `risk_tier_history` entries must name tier 1-3, prior, a non-machine `by`, a
  timestamp `at` and a reason; each `prior` must be the tier the entry before it set; the last entry's tier must be
  the tier the document states. No existing document carries the key, so no existing document changes verdict.
