### The change, on the wire

- **The Durable Object's thrown-op envelope.** Before: `{ ok: false, error: String(e && e.stack || e) }` at 500 — the
  stack, with this plane's module paths, line numbers and SQLite's own text. After: `{ ok: false, error: "internal error",
  reason: "STORE_INTERNAL_ERROR", code, check: "C-69.3", translation, correlation }` at 500. The stack is logged
  server-side (`console.error`) under `correlation`, a random UUID the caller also receives.
- **The control plane's thrown-request envelope, which did not exist.** Before: an uncaught exception to the Workers
  runtime (the platform's "error code: 1101"). After: `{ ok: false, error: "internal error", reason:
  "PLANE_INTERNAL_ERROR", code, check: "C-69.4", translation, correlation }` at 500, the stack logged the same way.
- **Where a caller meets the first:** on every route that relays the store's envelope as it stands — the pass-through
  route at the foot of the control plane's handler (credentialed ops), and the PUBLIC `op=invitelook`, `op=enroll` and
  `op=login`, which relay it at HTTP 200 (unchanged; D-679). Ops opened through `doAnswer` answer `STORE_DID_NOT_ANSWER`
  as before (REC-52) and do not move.
- **No named refusal moves.** A named refusal is RETURNED; these two catches see only a THROW. `UNKNOWN_OP` (400) and
  `NOT_AUTHENTICATED` (401) are re-asserted unchanged in `test/d629-internal-error.test.mjs` (R1, R2).

### Measured consumer impact

- **`civicos-ui/app.html`** reads a failure as `reason || error` (e.g. the refusal head, `reason · error`) and renders a
  plane `translation` where one is sent. It rendered the raw stack; it now renders the code, "internal error" and the
  canned sentence. `queueAbsent` and its siblings test `error` for `/unknown op/`, which neither new envelope contains
  — the same answer as before for every stack that did not happen to contain those words.
- **No suite asserted on stack text.** Measured by grep over `bio-plane/test` and `civicos-ui/test` on this base: the
  only producers of the old shape were two REC-52 failing-store fixtures that HAND-WROTE it (`fixtures/do-fail-worker.mjs`
  and the inlined one in `group-public.test.mjs`); both now build the envelope with the store's own `storeInternalError`
  from a real Error, corrected with a comment, never exempted. `d278-codeless-refusals.test.mjs` §6 assumed every C-69 row
  lives in `index.mjs` and is corrected to read the file the row's `where` names.
- **An operator** who read a failure's cause from the response now reads it from the Worker's log (`wrangler tail`),
  found by the `correlation` the caller was given.
