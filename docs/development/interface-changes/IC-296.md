- **Interface:** I3. I5 does not move: no table, column, index or write is added; the read writes nothing (the D-394 suite's whole-store witness still holds, 41/0).
- **Classification (proposed):** MINOR, ADDITIVE — new fields on an existing answer; no existing field's value, spelling or type changes and no refusal is added. `state`, `matched`, `reason`, `says` are exactly what IC-239 defined. CONDUCT resolves the version.
- **The new fields.** On each candidate: `grade` ∈ `A` · `B` · `C` · `NOT_FOUND` · `UNDETERMINED`; `affects` ∈ `unaffected` (A, B) · `affected` (C, NOT_FOUND) · `undetermined`; `grade_reason` ∈ `identical_at_extent` · `identical_elsewhere` · `similar_text` · `text_not_found` · `extent_unreadable` · `cited_as_bytes` · `cited_text_not_held` · `cited_text_truncated` · `cited_text_partial` · `newer_text_not_held` · `newer_text_partial` · `newer_text_truncated`; `grade_why` (a sentence); `found_at` (`{ extent, ref }` for A/B/C, else `null`); `similarity` (word-multiset Dice, 3 d.p., or `null`). On each notice: `affects` — `null` for `no_newer_capture` and `not_asked`, `undetermined` for `chain_unread`, else the roll-up over candidates (any affected → `affected`; else any undetermined → `undetermined`; else `unaffected`). On the envelope: `grades` — the five grades, each `{ affects, says }` (PL-17: the vocabulary travels with the answer).
- **Behaviour a consumer must not assume away:** `newer_capture_matched` with `grade: "C"` or `"NOT_FOUND"` is a real combination — the extent exists in the newer capture and the text at it changed. A surface that shows "matched" as "unchanged" makes the record claim more than it read; render `affects`.
