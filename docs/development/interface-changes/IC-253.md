### The change, on the wire

- **In:** `store: <namespace token>` becomes `store: "bio" | "scratch"`, exact and case-sensitive.
- **A named value outside that set** — `biosmoke`, `biosmoke-fleet`, `Scratch`, `BIO`, `a b`, the empty string — answers
  `400 { ok: false, reason: "NAMESPACE_UNKNOWN", code: "NAMESPACE_UNKNOWN", detail, worker: "agent-worker", asked, namespaces: ["bio","scratch"] }`,
  after `BAD_RUN_ID` and before the credential checks, the cascade and any plane call. Nothing is read or written. `asked` is
  truncated at 80 characters, as the plane's is. The code is the plane's own spelling (C-78.1): the set is fixed in the
  plane's code rather than per instance, so "no such namespace" is the same fact on every instance this member can be
  bound to. The member carries no `check`/`translation` fields: it has no member-facing surface and carries no DEC-49
  family (`src/index.mjs`'s note on `refusal`).
- **Absent or non-string `store`** still answers `400 BAD_STORE`, unchanged. (`a b` read `BAD_STORE` before and reads
  `NAMESPACE_UNKNOWN` now: it is a named value, not a missing one.)
- **Unchanged:** `store: "bio"` and `store: "scratch"`; every other field and every success shape.
