  I3 76.3.0 (IC-235).** Read the base AT RESOLUTION.

- **Proposer:** c18-batch7fix, CONDUCT's integration correction on the c17-batch7 union, 2026-09-24.

- **Design:** `docs/architecture/BIO_Publication_v0_1.md` §7 points 2 and 3 (REC-164) and §3 rule 11 (D-150); the
  bound rule every capped read in `bounds.test.mjs` is held to — a read that cuts publishes the bound it applied and
  says when it cut, so a cut answer and a complete one never read alike.

**WHY.** `bounds.test.mjs`'s walk found both ops on the c17-batch7 union, each capped by a SQL LITERAL that published
nothing, so neither could be driven: the PIN arm had no honest way to pass.
- `groupIdentity` (the credentialed arm of `op=groupidentity`) read `group_domain_checks … LIMIT 20`. A claim the
  alarm had re-checked past its twentieth verdict read as if its history began twenty checks ago — a domain that read
  `mismatched` before it read `verified` looked as if it had always verified.
- `acknowledgeStatement` (`op=statementack`) re-authored the unsigned case documents carrying the acknowledged
  statement under `LIMIT 8`, and the cut fell BEFORE the project filter (a document's project lives in its text), so
  eight unsigned documents carrying the same sentence anywhere in the store could crowd this project's own out of the
  re-authoring, leaving it to be signed without an acknowledgement that was given.

**THE SHAPE.** Each read takes ONE ROW PAST its bound, so the flag is MEASURED rather than inferred from a full page.
- `op=groupidentity` (credentialed arm only; the public projection is unchanged): `domain_checks` (newest first, at
  most `GROUP_DOMAIN_CHECKS_MAX` = 20, as before), plus `domain_checks_limit: 20` and `domain_checks_truncated`.
- `op=statementack`: `case_documents` (unchanged), plus `case_documents_limit: 8` (`STATEMENT_ACK_DOCS_MAX`) and
  `case_documents_truncated` — true when more candidate documents carried the statement than were examined.
Both constants sit BELOW their method, on REC-116's finding, so the bounds walk reads each as its op's `named-cap`.

**WHAT IS NOT CHANGED, stated:** neither bound moved; `op=statementack` still re-authors at most eight documents per
act, and a ninth is now SAID rather than silent. Whether the draft door's match (any unsigned edition-1 document in the
project carrying the sentence, across cases) should be narrowed to the draft's own authored document is a DESIGN
question this entry does not answer; it is routed to CONDUCT for SCHEDULER/BOB.
