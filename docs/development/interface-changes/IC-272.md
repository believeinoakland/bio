### The change, on the wire

**The case document (`bio-case-document/3`), in its signed frontmatter — the shape a stranger holding the container reads:**

- `completeness.statement_by: <member id> | null` — **NEW, and REQUIRED as a key of a `/3` (C-41.13); `null` is legal and
  is a STATEMENT** (the plane could not establish who wrote the sentence). `completeness.author` is UNCHANGED in spelling,
  type and meaning: the member who prepared and published the case and authored this block at that act.
- Its position is `  author:` → `  statement_by:` → `  at:`, i.e. ABOVE `  statement_sha:`, which is load-bearing:
  `#reauthorAcknowledgements` re-splices the frontmatter run that STARTS at `  statement_sha:`, so a key written below it
  would be dropped by the next acknowledgement landing on an unsigned document (asserted by d150 block 5's
  only-the-list-moved arm, and by this item's block 2).
- **In the BODY**, one new line above the acknowledgement prose: `**Who wrote this statement.** <sentence>`, which names
  the writer AND where the record got the name (a draft's stamp, this publishing act, or which UNDETERMINED and why). It is
  above the prose head `#reauthorAcknowledgements` splices from, so an acknowledgement leaves it alone.

**`op=publish`'s answer** — `completeness` gains `statement_by`, `statement_by_stated`, and, only when non-zero,
`acknowledgements_by_statement_writer_not_listed` and `acknowledgements_withheld_writer_undetermined`.
`acknowledgements_by_author_not_listed` is UNCHANGED IN MEANING (the publisher's own, counted apart from every exclusion
added since D-150, so a caller reading that number reads the same fact).

**`op=caseratify`'s answer** gains `statement: { author, by, stated }`, read once from the bytes it commits.

**`op=publishedcase`** serves `completeness.statement_by` and `completeness.statement_by_stated`, **committed from the
SIGNED bytes at ratification and never from `author`**. THREE states are told apart and `statement_by_stated` is what tells
them apart for a reader: a NAME; `null` where the document SAYS undetermined; and a document authored before this key
existed, which says NOTHING (both of the last two serve `statement_by: null`, with different sentences).

**How the writer is established at publish** (`Store#statementWriter`, and it measures nothing new): the DRAFT stamp
REC-193 already records, carried by the statement's OWN identity — `#fmSafe`, the normalisation `#statementSha` hashes and
the one REC-193's own stamp compares — at the case identity `#statementAcknowledgements` binds an acknowledgement to. Four
answers, each a fact: drafts agreeing → that member; NO draft at this identity holding the sentence → the PUBLISHER, who
wrote those bytes in this act (`op=publish` takes `statement=` as an authored argument and refuses `NO_STATEMENT` without
one); a matching draft recording no author, or two matching drafts naming different members → UNDETERMINED; more drafts
than one bounded read lists (`REVIEW_LIST_MAX`, `op=casedrafts`' own bound) → UNDETERMINED, with that reason.

### What is NOT in this change, stated

- **No SURFACE reads `statement_by` off a case document** (the delegation above).
- **`op=reviewcopy`'s LIVE list is deliberately unchanged.** It shows a reader every acknowledgement recorded, ahead of the
  act that decides what a document may print (its own rule since D-150: the review list is *less the publisher's own,
  which the act leaves out*). So a participant row recorded BEFORE REC-193 — when the draft door read the last editor —
  that may be the writer's own is still shown there, while the case document withholds it. Stated, not fixed here: fixing
  it would change what a reviewer is shown, which is §6A's shape and not this row's.
- **The one-case-identity narrowing stays rowed (REC-194)**, running beside this item.
- **The residue of the no-draft answer, named because the document prints its provenance sentence FOR it:** a publisher who
  RETYPES a sentence an editor wrote in a draft that has SINCE BEEN EDITED is credited with writing it. No draft holds
  those bytes any more and the record keeps no history of a draft's statement text to ask. A caller who wants the editor
  named publishes the statement the draft holds.
