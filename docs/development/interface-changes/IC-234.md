## IC-234 · I3: `op=queue` carries a new OBLIGATION producer — `bias-debt`, one item per run whose lens moved, with a subject of kind `run` · PROPOSED 2026-09-23 (D-86; id taken with `node tools/mintid.mjs IC` before this file was written — IC-230 was minted first and found taken on `land/conduct/c17-batch7`, so it was not used) (D-86; minted on its clone as IC-231, which collided with REC-149's IC-231 on `land/conduct/c17-batch7`, and RENUMBERED IC-234 by CONDUCT #18 with `node tools/mintid.mjs IC` at c17-batch7)

- **Interface:** I3 (the op contract). I5 moves ADDITIVELY: two new tables, `bias_debts` and `bias_debt_sweeps`, both cleared
  by `op=purge`'s whole-store arm; no existing table or column changes.
- **Classification (proposed):** MINOR, ADDITIVE. No op is added, removed or refuses anything new. `op=queue` answers the
  same envelope; its `items[]` may now include items with `class: "OBLIGATION"`, `kind: "bias-debt"` — a kind
  `queuestate.mjs` has catalogued since REC-47 and that no producer emitted. CONDUCT resolves the version.
- **The item's shape** (NOTIFICATIONS.md §The item contract), beside the task-backed OBLIGATION's:
  - `id`: `OBLIGATION::bias-debt::<run>` — one per run.
  - `subject`: `{ kind: "run", id: <run>, context: { type, id } }` — **a subject kind no producer emitted before.**
  - `basis`: `{ source: "bias_debts", computed_by: "aiRunRead", run, moved: true, moved_basis, lens_then, lens_now,
    observed, stated, detail }` — `lens_then` / `lens_now` are the two `statements_sha` values `op=airun` publishes
    (`null`, stated in words, where no lens was in force).
  - `assignee: null`, `assignee_role: null`, and a NEW key `recipients: [member ids]`, plus `recipients_stated` when
    none could be named (the item is then shown to every member who can read the run).
  - `age` from the row's `raised`; `options` from `#queueOptions` over the run's context bundle.
- **The alarm's answer** (`onAlarm`, not an op) gains a `biasdebt` key when the consumer ticks:
  `{ read, raised[], restated[], cleared[], undetermined[], unchanged, complete, batch }`.
- **Measured consumer impact:** `civicos-ui/app.html` `queueSubjectHtml` renders a subject by `kind` and returns `""` for
  a kind it does not know (read at the code, 2026-09-23), so a bias-debt item renders its summary, basis and options
  with NO subject line — it degrades to silence about WHICH run, not to an error. `renderQueue` needs no change to show
  the item. Nothing else in the repository reads `op=queue`'s `subject.kind` (`grep -rn "subject.kind"` over
  `civicos-ui/`, `agent-worker/`, `newgroup/src`: one site). The UI half is a DELEGATION, not part of this change.
