## IC-244 · I3 + I5: §4.9's custodial acts (`memberadd`, `memberset`, `signeradd`, `signerset`) are every administrator's — reached from an enrolled administrator's own session, the actor stamped by the server, and `status_by` recorded · ACCEPTED 2026-09-24 (REC-159)

*Written at integration by CONDUCT #19 (2026-09-24): REC-159's report named its IC as "to mint" (I3 + I5 `status_by` columns); the id was taken through D-242's coord minter. The substance below is read from REC-159's commit `e4f0c582` and its code, not from a proposal.*

- **Interface:** I3 (the op contracts) and I5 (the store schema).
- **Design:** `docs/architecture/BIO_Membership_Architecture_v2.md` §4.9 and §4.7's block *"WHAT IS STILL NOT CLOSED"*; scope amended by BOB #31 (the record half) and BOB #22 (the operator's bearers keep the acts).
- **What changes, I3:**
  1. **Reach.** `CUSTODIAL_ACTIONS` = `memberadd`, `memberset`, `signeradd`, `signerset` are in BOTH `SESSION_OPS` sets, and `member` joins each OPS row's classes: an enrolled administrator performs them from her own session instead of being refused with a sentence calling the op an administrator's.
  2. **The stamp.** The server sets `by` on all four — a session's member, or `class:<cls>` for a bearer — after the caller's parameters are copied; the store's relays read `by` from the query over anything in the body. **A caller-supplied `by` is no longer honoured on `memberset`, `signeradd` or `signerset`** (it already was not on `memberadd`, REC-156).
  3. **The roster.** Each store method refuses a member-named `by` that is not an ACTIVE administrator, `NOT_AN_ADMIN`, before any lookup (`Store#custodialBar`).
  4. **Bearers.** Each row's `machineClasses` is `["admin","probe"]`: the operator's bearers keep the four acts (BOB #22), their `by` naming no person; the `MEMBER_TOKEN` bearer and an `ai` credential stay out, as before.
- **What changes, I5:** `members.status_by` and `signers.status_by`, nullable TEXT, written with the stamped actor by `memberset`, `signeradd` and `signerset`; never back-filled; a NULL reads back as `not recorded`.
- **Evidence:** `bio-plane/test/adminvote.test.mjs` §9 (one arm per op; control 15/15 arms as declared, incl. `custodial-stamp-dropped`), `d270-refusal-truth` (control 8/8), `admission-gate`, `members`, `d311-roster-affordances` — corrected, never exempted.
