### The mechanism this item found on the way, because it changes what the IC is claiming

**The wire effect would have arrived from the catalogue rows alone.** `src/index.mjs` already carries a GENERIC DEC-49 DECORATOR — `dec49Decorate`, reached from `dec49Attach` — which walks every `ok:false` answer the control plane sends, resolves its `reason` across EVERY `*_CHECKS` family by the reserved suffix (a property, not a list), and fills in `code`, `check` and `translation` when they are absent. Measured by driving `op=knock` with the store reverted to `{ ok: false, reason: "RATE_IP" }`: the 429 still came back carrying `code`, `check` and the canned sentence.

So this IC's additive keys are delivered by TWO independent mechanisms once the rows exist. The region and the helper are kept — the row's scope asks for them, the DEC-49 guard needs a true mint site for each row's `where` to name, and they make `Store.knock`'s own return carry the paper for any consumer that does not come through the control plane — but a reader of this IC should know that **removing the store-side region would not change this wire**, and that no single behavioural arm can see either mechanism. `test/nc-d508.mjs` disables each alone and then both together for exactly that reason.
