### The change, on the wire

- **ONE ADDITIVE KEY on a capture entry none of whose captures has a locator row** (bytes a provenance document carried,
  a member's upload): `fetch: { route: "unrecorded", unrecorded: <n>, earned: null, earned_via: null, determined: false,
  undetermined_because: "CAPTURE_ROUTE_UNRECORDED", why: <sentence> }`. Until this change such an entry carried no
  `fetch` key at all. Every other key of the entry is byte-identical (measured: REC-88's cross-checkout digests in
  `content-capture-bound.test.mjs` §5 and `content-reads.test.mjs` §7 still match over the entry less this key).
  An entry with a recorded route (D-177 direct, D-693 archive, an unruled via, or the partial case) is UNCHANGED and
  carries no `route` key. `CAPTURE_ROUTE_UNRECORDED` is a reason code on the entry, not a refusal (no DEC-49 row).
- **A READ THAT RETURNED NO REASON NOW RETURNS ONE.** `Store.#capturedAt` — behind the strength walk
  (`op=inquirystrength`, `weakest.why` / `not_load_bearing[].why`), `op=meaningrows&rows=leg` (`grade_why`),
  `op=reevaluations` (`legs[].grade_why`) and a version's legs (`op=versionstrength`) — returned `null` for a letter at or
  under the ceiling. On an entry whose route is unrecorded it now returns the SAME letter with
  `why: "this leg is read here at its author's own <X>, not over <Y>: the record does not say where <doc> came from,
  so that grade has not been checked."` (worded in the member lexicon `analystvocab.test.mjs` §4a enforces.) Above the ceiling the cap is unchanged and its reason
  gains one sentence saying the route is unrecorded. **No letter moves in either direction**; only a null reason becomes
  a sentence.

### Why MINOR, by IC-25's test

Nothing that answered refuses, no key is renamed, retyped or removed, and no grade letter moves. A field that was `null`
now carries a string on one class of leg (`grade_why`, `weakest.why`): a caller that tested `grade_why == null` to mean
"nothing was capped" now reads a reason on an uncapped leg whose route is unrecorded. That is the ruling's intent (BOB
#35: an unmeasured letter must not read as a silent one), and it is the one behavioural edge CONDUCT should weigh.
