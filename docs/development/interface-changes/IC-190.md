## IC-190 · I3: `op=promote` REFUSES A DIGEST THAT IS NOT OF THE BYTES — every inline file's SHA-256 is computed over its UTF-8 bytes and a supplied `sha256` naming another is refused `FILE_DIGEST_MISMATCH` (C-33.38) before anything is written; a blob's supplied `sha256` must name its `blobSha`; an absent digest is computed; and a new read, `op=digestcensus` · PROPOSED 2026-09-23 (REC-175, minted with `node tools/mintid.mjs IC` BEFORE the entry was written) — the version bump, the classification and the RESOLUTION are CONDUCT's

- **Interface:** I3 (the op contracts). I5 does not move (no table, no column; the census reads `files` and `history`).
  **Base read off THIS TREE (`origin/main` @ `14faa089`): I3 58.3.0 (IC-189).** The brief says I3 will be 59.1.0 after
  CONDUCT's next train — **read the base AT RESOLUTION.** **Proposed I3 MAJOR, BREAKING** — 58.3.0 → 59.0.0 on this base.
  **Why BREAKING:** a request that answered `ok: true` is now refused — a promote whose `sha256` is not the digest of the
  file's bytes (on bundle.md or ANY other file), and a blob file whose `sha256` differs from its `blobSha`. The precedent is
  IC-176/IC-177's: a refusal where there was an acceptance is a break however few callers meet it. The ADDITIVE halves ride
  with it: `sha256` becomes OPTIONAL on an inline file (the plane computes it; before this, an absent one failed the `NOT
  NULL` column with a platform error), an upper-case spelling of the right digest lands and is stored lower-case, and
  `op=digestcensus` is a new read.

**THE SHAPE.** `store.mjs` `promote`, `DEC-49 REGION is-promote-digest`, immediately after `MALFORMED` and BEFORE the
transaction (a refusal returned inside `transactionSync` does not roll back): `Store.#digestFiles(files)` computes each
file's digest by the ONE `Store.#fileDigestOf` — an inline file over `new TextEncoder().encode(text)`, the UTF-8 of the
string the `files.content` column stores, never a normalised copy; a blob over its `blobSha` — and returns the files with
every digest the computed lowercase value, plus each file whose supplied value named another. It runs BEFORE REC-141's mint
and D-436's group stamp (which rewrite bundle.md and recompute its digest from what they wrote), so the caller's claim is
judged against the bytes the caller sent. **Replay is not exempt.** `index.mjs`'s D-78 restamp (an inquiry creation's
`surfaced_by`), which recomputes bundle.md's digest after rewriting it, now runs only when the caller sent no digest or the
digest OF THE TEXT IT SENT — otherwise the bytes and the false digest go to the store as sent and are refused by name,
rather than laundered into a true one with `ok: true`.

**THE WIRE.** Refusal: `{ ok: false, reason: "FILE_DIGEST_MISMATCH", code, check: "C-33.38", translation, paths: [..],
files: [{ path, kind: "inline"|"blob", supplied, computed }], detail }`. `op=digestcensus` (admin, probe; `limit` default 50,
max 500): `{ ok: true, files: { rows, inline, blob, digest_disagrees, bytes_disagree, listed: [{ bundle_id, path, stored,
computed, digest, bytes_stored? }] }, history: { … same, with snap_key, bytes not judged }, rewritten: 0, note }`.

**WHAT IS NOT CHECKED, stated:** whether R2 holds a blob's bytes (D-45 — refused at RATIFY, `PLANE_MISSING_BYTES`); the
`bytes` figure on any file (a separate finding, counted by the census — see M-115).
