### The class the third row belongs to, swept

**THE ASSEMBLED SPELLING** — a tool or script reached as `join(…, "tools", "x.mjs")`, the directory and the file as
two arguments and the slash never written. It is the same act as `tools/x.mjs`, and neither `TOOL_RE`, `SCRIPT_RE`
nor `IMPORT_RE` could see it; a comment could cover it, and comment-blanking took that cover away.

Swept over the **840 `.mjs` files** of `bio-plane/test`, `civicos-ui/test`, `civicos-ui`, `tools` and
`bio-plane/scripts`, reading each file through the same lexer:

- **24** files spell a tool or script this way in CODE;
- **13** of those spell that name NO other way in code;
- **8** had the literal `tools/x.mjs` or `scripts/x.mjs` in a COMMENT alone, so blanking comments would have lost a
  REAL edge: `entries.control.mjs` (→ `tools/entries.mjs`, `tools/mintid.mjs`, `tools/ledger.mjs` — the very tools it
  drives), `gateverdict.test.mjs` (→ `tools/pushguard.mjs`, `tools/gateverdict.mjs`), `train.control.mjs`
  (→ `tools/pushguard.mjs`, `tools/train.mjs`, `tools/gates.mjs`), `debt-floor.control.mjs`,
  `mintid-freshclone.control.mjs`, `provenance-floor.control.mjs`, `tally-through-pipe.test.mjs` and
  `tally-through-pipe.control.mjs`.

Reading that spelling closes all eight. **WHAT THE MATCHER CANNOT SEE, stated:** only the two-argument literal form.
A name built from a variable (`join(REPO, "tools", NAME + ".mjs")`, which `gates.test.mjs`'s own `computed.test.mjs`
fixture uses), a three-segment join, a template with an interpolated name, or a shell string handed to a spawn is
invisible here and still is — those are reached, when they are reached at all, by MENTION of the basename or stem,
and a unit that names none of them is not selected. `tools/nc-m039.mjs` names `tools/.mintid-nc-m039.mjs` this way
and is not a unit.
