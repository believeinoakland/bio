### What changed in the instrument, and why

`bytesOf` accepted any response the origin LABELLED `application/pdf`. The row's accepts-when is about **bytes**, and
those are different claims: a CDN error page, a login interstitial or a "moved" stub served under a PDF content-type
would have been cached and handed to the extractor, which would report NO-TEXT-LAYER — a decode outcome
indistinguishable in the coverage table from a real scanned page. So the `%PDF` magic is now checked on the fetched
bytes AND on the cached copy (a cache poisoned once otherwise survives every later run, offline and unexamined), and
it names itself: `NOT_PDF — <where> begins <first bytes>, not "%PDF"`.

`--urls` is new and is the durable half. It separates four outcomes the old probe collapsed into one FAILED row:
**LIVE** / **NOT_PDF** / **NOT_FOUND** (404/410 — the ONLY outcome that means re-point the manifest) / **REFUSED**
(the request never reached the origin, or the origin refused it — a claim about THIS HOUR and this session, never
evidence that a document moved or is absent). **That distinction is the whole reason this row existed**, and building
it into the instrument is what stops the next closed-egress session from re-raising it.

### What this measurement CANNOT see

- **It is one hour's answer.** `14/14 LIVE` is true of 2026-09-24 03:15Z from this container, through this session's
  proxy. It is not a claim about the hosts' future, and a later REFUSED is an egress claim about that hour, not a
  refutation of this one.
- **It checks the first four bytes, not the whole file.** A truncated or corrupt PDF that begins `%PDF` reads LIVE.
  The full coverage run is what exercises the rest, and it is not part of the preflight because it costs 75 MB.
- **`--urls` reads the manifest, so it can only check URLs the manifest NAMES.** It says nothing about whether those
  fourteen are still a representative spread of Oakland's classes in 2026 — that is a corpus-design question this row
  did not open.
- **No document was NOT FOUND, so the `NOT_FOUND` branch was exercised by no live URL** — only by reading its code.
  Arms A and C exercise `NOT_PDF`; `REFUSED` and `NOT_FOUND` are unexercised against a real origin.
