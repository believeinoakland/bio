**THE BOUND, AND THE RULE THAT GIVES IT — stated so the next measurement moves it by the same rule, not by judgement.**
`navigation_timeout_ms` = (2 x the measured tail) + 5,000 ms held for the session acquisition nobody has measured, rounded
UP to the next whole 5,000 ms: 2 x 1,300 + 5,000 = 7,600, so **10,000 ms**. The doubling is the stated allowance for the
instrument not being Cloudflare's browser or network; the 5,000 ms is CHOSEN, NOT MEASURED, and is the one term the first
live render replaces (its `elapsed_ms` is the renderer's claim of the whole). With the wait's 15,000 ms the reservation is
**25,000 ms** (was 45,000). The driver now HOLDS this bound (D-520): before, it bounded `Page.navigate` by the wait timeout
and every setup command by a 30,000 ms default, and never read `navigation_timeout_ms` at all.

**THE FINDING THE ROW DID NOT PREDICT (D-570).** On both opengov addresses the load event fired in 3.6–9.0 s and the page
then NEVER went network-idle — 16 of 16 runs, each held the full 60 s, 73–77 requests with at least one never finishing.
The plane asks `wait: { until: "networkidle", timeout_ms: 15000 }`, so every render of this source will END ON ITS TIMEOUT:
it is filed (BOB #32's timeout ruling), reads "render may be incomplete (wait timed out)", and spends the whole 15 s of
browser time it reserved. The page had its content well before that; the wait condition, not the page, is what is
undetermined. The fix needs a design choice (which wait condition counts a page as settled when it keeps a request open)
and is routed to BOB, not taken here.

**The harness, whole** (run as `PROXY_CA_SPKI=<spki> RUNS=8 node measure.mjs <addresses…>` from a directory holding `puppeteer-core@23`):

```js
// D-520 navigation measurement. Local headless Chromium (Playwright's build at
// /opt/pw-browsers/chromium) driven over CDP through puppeteer-core, mirroring
// bio-plane/src/browserrender.mjs's wait rule: load event, then 0 requests in
// flight for IDLE_QUIET_MS = 500. Each run is a fresh incognito context.
import puppeteer from "puppeteer-core";

const URLS = process.argv.slice(2);
const RUNS = Number(process.env.RUNS || 5);
const CAP_MS = 60000;
const IDLE_QUIET_MS = 500;

const browser = await puppeteer.launch({
  executablePath: "/opt/pw-browsers/chromium",
  headless: true,
  args: ["--no-sandbox", `--proxy-server=${process.env.HTTPS_PROXY}`, `--ignore-certificate-errors-spki-list=${process.env.PROXY_CA_SPKI}`],
});
console.log("engine", await browser.version());
const rows = [];
for (const url of URLS) for (let i = 0; i < RUNS; i++) {
  const ctx = await browser.createBrowserContext();
  const page = await ctx.newPage();
  await page.setViewport({ width: 1280, height: 800 });
  const cdp = await page.createCDPSession();
  await cdp.send("Network.enable"); await cdp.send("Page.enable");
  let inflight = 0, loadAt = null, dclAt = null, quietSince = null;
  const t0 = performance.now();
  const ids = new Set(); let total = 0;
  cdp.on("Network.requestWillBeSent", (e) => { if (!ids.has(e.requestId)) { ids.add(e.requestId); inflight++; total++; } quietSince = null; });
  const done = (e) => { if (ids.delete(e.requestId)) inflight--; };
  cdp.on("Network.loadingFinished", done); cdp.on("Network.loadingFailed", done);
  cdp.on("Page.loadEventFired", () => { loadAt = performance.now() - t0; });
  cdp.on("Page.domContentEventFired", () => { dclAt = performance.now() - t0; });
  let commitAt = null, err = null, idleAt = null, status = null;
  cdp.on("Network.responseReceived", (e) => { if (e.type === "Document" && status === null) status = e.response.status; });
  try {
    const nav = await cdp.send("Page.navigate", { url });
    commitAt = performance.now() - t0;
    if (nav.errorText) err = nav.errorText;
  } catch (e) { err = String(e.message || e); }
  while (!err && performance.now() - t0 < CAP_MS) {
    if (loadAt !== null && inflight <= 0) {
      if (quietSince === null) quietSince = performance.now();
      else if (performance.now() - quietSince >= IDLE_QUIET_MS) { idleAt = performance.now() - t0; break; }
    } else quietSince = null;
    await new Promise((r) => setTimeout(r, 25));
  }
  const r = { url, run: i + 1, status, commit_ms: commitAt && Math.round(commitAt), dcl_ms: dclAt && Math.round(dclAt),
              load_ms: loadAt && Math.round(loadAt), idle_ms: idleAt && Math.round(idleAt), requests: total, err };
  rows.push(r); console.log(JSON.stringify(r));
  await ctx.close();
}
await browser.close();
console.log("ROWS", JSON.stringify(rows));
```
