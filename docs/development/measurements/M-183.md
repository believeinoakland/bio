## M-183 · 2026-09-25 · D-690: the DEC-49 guard loses its tail through a pipe ON LINUX, and the D-282 flush import stops it

**What this measures.** Whether `civicos-ui/check-refusal-codes.mjs`, which ends in `process.exit(1)` on its
failure path, delivers all of its output to a PIPED reader under parallel load once D-542 grows that output
from ~38 KB to 61 KB — and whether `import "../bio-plane/test/stdio.mjs";` (D-282's flush module) on line 2
closes it. Measured on a scratch merge of `origin/main` @ `5e8a65a8` with `land/worker/D-542` @ `fac514e0`
(a fast-forward: the union IS `fac514e0`), in a detached worktree in the session scratchpad; nothing measured
here was run on the branch that carries the fix.

**The answer.** Without the import, **3, 13 and 6 of 32** runs lost bytes (three trials); with it, **0 of 32
twice (0 of 64)**. Every loss cut stdout at the same place (32,337 of 61,033 bytes, and the reference's final
ratchet line absent); stderr (800 bytes, the FAIL lines and the failure count) arrived whole in every run
observed. **This contradicts `bio-plane/test/stdio.mjs`'s header, which says the defect "cannot occur at all"
on Linux** — filed as D-691, not fixed here.

### Instrument

- Host: `Linux 6.18.44-fc-v37`, 4 CPUs (`nproc`), node `v26.10.0`, 2026-09-25 (cloud WORKER D-690).
- Plant: `CEILING.multiSiteCodes` 59 -> 60 in the union's guard, so the guard FAILS with one CEILING SLACK
  line and exits through `process.exit(1)` (reference exit 1, stdout 61,033 B, stderr 800 B).
- Driver (scratchpad `D-690-trial.mjs`, sha256 prefix `f8d8819f17399528`, reproduced verbatim below): one
  file-captured reference run, then `N` children spawned at once with `{stdio:"pipe"}` — the shape `run.mjs`
  and every control driver use — for `R` rounds. A run is TRUNCATED when its stdout or stderr differs from
  the reference's bytes or lacks the reference's final line. Invocation: `node D-690-trial.mjs
  civicos-ui/check-refusal-codes.mjs 16 2` (16 parallel x 2 rounds = 32 runs).

trial lost anything.

### What this does not establish

- WHY Linux loses here when node's documentation (a vendor's claim) says pipes are synchronous on Linux. The
  reader's `{stdio:"pipe"}` is a UNIX-domain socketpair, not a FIFO; that is a candidate mechanism, not a
  measured one. Undetermined.
- `check-semantics.mjs` and `check-mock-envelope.mjs` got the same import (same residual, M0-36's ARM D) and
  were NOT trial-run: their output on a failure is far below 32 KB. Their repair rests on the mechanism above
  and on `stdio-census.test.mjs` ARM D1, which fails naming any of the three that loses the import (run:
  `check-semantics.mjs` import deleted -> `14 pass, 1 fail`, ARM D1 naming it; restored by `cp`, sha256
  `b2f0e2d7bc34b193…` = pristine; a BOUND spelling of the import passes, 15/0).
- D-387's half (`check-mock-envelope.mjs` as a piped READER on node's 1 MiB default `maxBuffer`) is untouched.

### The driver, verbatim

```js
// D-690 truncation trial: N parallel runs x R rounds of a guard, spawned with stdio "pipe"
// exactly as run.mjs / a control driver does; a run is TRUNCATED when the byte count differs
// from a file-captured reference or the final line of either stream is absent.
import { spawn, spawnSync } from "child_process";
import fs from "fs";
const [guard, N = "16", R = "2"] = process.argv.slice(2);
const ref = spawnSync(process.execPath, [guard], { stdio: ["ignore", fs.openSync(process.env.REF_OUT, "w"), fs.openSync(process.env.REF_ERR, "w")] });
const rOut = fs.readFileSync(process.env.REF_OUT, "utf8"), rErr = fs.readFileSync(process.env.REF_ERR, "utf8");
const lastLine = s => s.trimEnd().split("\n").pop();
const tailOut = lastLine(rOut), tailErr = lastLine(rErr);
console.log(`reference (file capture): exit ${ref.status}, stdout ${Buffer.byteLength(rOut)} B, stderr ${Buffer.byteLength(rErr)} B`);
console.log(`  stdout tail: ${tailOut.slice(0, 100)}`);
console.log(`  stderr tail: ${tailErr.slice(0, 100)}`);
const one = () => new Promise(res => {
  const c = spawn(process.execPath, [guard], { stdio: "pipe" });
  const o = [], e = [];
  c.stdout.on("data", d => o.push(d)); c.stderr.on("data", d => e.push(d));
  c.on("close", code => { const so = Buffer.concat(o).toString(), se = Buffer.concat(e).toString();
    res({ code, ob: Buffer.byteLength(so), eb: Buffer.byteLength(se),
          ok: so === rOut && se === rErr && so.includes(tailOut) && se.includes(tailErr) }); });
});
let trunc = 0, total = 0;
for (let r = 0; r < +R; r++) {
  const rs = await Promise.all(Array.from({ length: +N }, one));
  for (const x of rs) { total++; if (!x.ok) trunc++; }
  console.log(`round ${r + 1}: ${rs.filter(x => !x.ok).length} of ${N} truncated · stdout bytes [${rs.map(x => x.ob).join(",")}] · stderr bytes [${rs.map(x => x.eb).join(",")}] · exits [${[...new Set(rs.map(x => x.code))].join(",")}]`);
}
console.log(`D-690 trial: ${trunc} of ${total} truncated`);
```
