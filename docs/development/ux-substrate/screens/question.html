S6. Using a Claude subscription without a command line

What you are asked: how a member who isn't technical can use their own Claude Pro or Max subscription with the assistant.

Why it is yours: each way out depends on how Civicsmith is built and on what Anthropic's terms allow, and one of them means asking Anthropic for something.

How it works today

A subscription token is made only by Anthropic's own sign-in, started from Claude Code with claude setup-token. A member has to install Claude Code and type a command, then paste the token into Civicsmith. An API key, by contrast, is made entirely in a web browser, at Anthropic's Console. The screen now says this plainly, puts the API key first and suggests asking a technical member for five minutes' help.

What Anthropic's terms say (as the development process recorded them on 6 October)

  • "Anthropic does not permit third-party developers to offer Claude.ai login into their own applications" (AT-16), and "Unless previously approved, Anthropic does not allow third party developers to offer claude.ai login" (AT-19).
  • Sign-in "must complete through Anthropic's own flow", and developers may not "collect, store, or intermediate Claude.ai credentials or session tokens" (AT-17).
  • Nothing prevents "an end user from signing in to the unmodified Claude Code binary with their own Claude subscription, including where a platform hosts Claude Code" (AT-18).

An example

Ana has a Claude Pro plan and uses it on her phone. She would like the assistant in Civicsmith to use it too. Today she would have to install Claude Code on a laptop and type a command; she won't. So she uses the group's key, or goes without.

S5. A group whose place Civicsmith doesn't know yet: A for now, recorded

Your answer, 6 October: “S5: A for now, but the B capabilities should be recorded as something to be done after the first public release goes out.” Recorded as DEC-151. For now, only the places Civicsmith ships, researched with their sources: a group elsewhere chooses “Other”, names its place, and is told when an update brings it (DEC-150). After the first public release, a group may write its own place's rules inside its own Civicsmith, each with its source, marked as the group's own research and serving only that group. That is recorded for the development process as work for after the first public release.

S3. The group's own API key: answered, 6 October

You ruled it through the development process (6 October, correcting how your words of 5 October had been recorded): three options. A group may hold one Anthropic API key, off by default, serving members who have no account of their own, each told once before their first question under it; a member may connect their own subscription token, used only by them, or their own API key; and a group may run without the assistant. Drawn: setup now offers the group's key, members' own accounts, both, or no assistant; the members screen shows the key's state, its switches and spending by member (never what was asked); the connect screen tells a member once that they can use the group's key and what that means; and the assistant panel says which account it runs on.
