# The closing prompt (pasted at the end of every claude.ai round)

Copy everything below the line.

---

We're done with this round. Write the round summary now, in exactly this format, as one markdown
block I can copy. Don't add anything outside it.

```
# Round summary: <round id and title>
Date: <today>

## Concepts
For each concept we discussed: a name, 2–4 sentences on what it is and how a person experiences it,
and its status: FAVOURED / CONSIDERED / REJECTED.

## Bob's reactions
What Bob said he liked, disliked or wanted, in his own words where possible, quoted.

## Rulings Bob made
Anything Bob stated as a decision. Quote it. Write "none" if none.

## Open questions
Questions we raised and didn't settle. Say who would have to answer each.

## Assumptions I made about the system
Every point where I assumed something about how BIO works, or what it has built, that the packet
did not state. Be exhaustive. These will be checked against the record.

## Suggested next round
One sentence.
```
