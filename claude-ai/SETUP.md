# Setting up the claude.ai project (Bob, one time, about 3 minutes)

1. In claude.ai: **Projects → Create project**. Name it **BIO UX Study**.
2. **Instructions:** open the project's instructions box and paste the whole of
   `claude-ai/PROJECT-INSTRUCTIONS.md`.
3. **Knowledge:** upload `claude-ai/GLOSSARY.md`. Add nothing else. Each round brings its own packet,
   so the permanent knowledge stays small.
4. **Settings:** make sure extended thinking and web search are on.

That's all. Each round then starts with a new chat inside this project (see `rounds/PLAYBOOK.md`,
step 2).
