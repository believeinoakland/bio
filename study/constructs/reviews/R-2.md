## Verdict

**LAW: sound with the corrections listed.** The core recommendation (move `standards` whole to layer 5, keep `conformance` in layer 9, adopt the work/version/portion model, staged) is supported by the code and the canon. The three corrections that matter most:
1. **Show Bob the registration alternative** (retrieval R53's pattern) and say when the move becomes necessary: when contradiction's canons, publication's Criteria or inquiry legs must call `standards` in code. Stage 1 alone does not require it (Error 6). Put stage 1's assistant help behind VF-4 and the model key (Error 5).
2. **Delete the false `LAW_LEVELS` conflict.** It was unified by K108 (1) and the code imports the four levels (Error 1). Fix the DEC-114 misreading (Error 2).
3. **Measure how the official code is served before relying on watching it.** Municode is client-rendered, and monitoring R5 cannot see content changes in a rendered capture (Error 8). Settle the within-layer position against ORGANISATIONS: LAW's "before `progressions`" is the one that works.

**COURTS: sound with the corrections listed.** The target (L3), the shape (a proceeding as a subject, a stage flow, register rows as captured extents, duties via ORGANISATIONS/LAW) and the decisions put to Bob stand. The three corrections that matter most:
1. **Following a register is not supported by today's monitoring** for rendered or cookie-gated portals: rendered content is undetermined each tick, credentials are not used by ticks, and no row diff exists. A member also cannot switch a watch on today (Errors 1–3). Stage 1 must close this, or state that it follows only static registers.
2. **Fix the private-name leak.** A caption used as the proceeding's label becomes an indexed alias. Label by forum, number and neutral description, and keep the caption as an extent only (Doctrine).
3. **Reconcile the interfaces.** ORGANISATIONS' closed line kinds and `OBL-` lack `party_to`, the proceeding-to-proceeding links, `arising_in` and reported status. LAW's relations lack `interprets` and `holds_invalid`. Name the citation check's module. Move the member words "proceeding" and "register" to Bob (P17).
