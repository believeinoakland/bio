## What these documents are
- **inquiry-grammar** (L6): pure grammar of an inquiry document as the record checks it: entry requirements per state, division block, leg grammar (grounds, testimony, earned, inherited arms), recheck coverage (C-15.1), lead checker (C-54.1), imported-finding reference (C-21.3); registers into record-core's grammar seam. Moved from the legacy catalogue.
- **inquiry** (L6): the inquiry (question) lifecycle: state machine, basis legs and how each is graded, ground partition (DEC-32), exclusions, supersession, division, the earned registry (what the record earns for a leg: connection grade = resolution of the target's captures to the inquiry's one subject entity), dispositions, the contradiction inquiry vocabulary (N345). No conclusion, version or strength.
- **citation** (L6): the act "this is why I think that": cite (legs on an inquiry, `cites` edges on a project), sever/reinstate (status changes only), and the one "may this be cited" predicate (not retired). Only information or inquiry bundles are citable.
- **strength** (L6): the derived pair (weakest capture, weakest connection; testimony beside, never composed), DEC-32 arithmetic over grounds, independence of grounds by shared provenance origin, anonymous-testimony rules (DEC-102), grading method version and recomputation from a case file (DEC-112), the bar (project's declared standard of evidence).
- **basis-versions** (L6): named, frozen alternative accounts of an inquiry's support; six-act state machine (member-only); a project's CURRENT; conclusions as append-only project rows; narrowing a leg to a part; the AI's only basis write path (`appendVersion` in `suggested`).
- **run-rules** (L6): pure rules of an AI run: bounds, endings, statuses, principal/project gates, skill-version form, state size, the one deployment order of run modes (check, investigate, extract, plan), refusal rows.
- **ai-runs** (L6): the AI run as a durable, bounded, attributed record object over a question or project: open/tick/close, one exit, reaping, wake on capture completions, lens and bar recorded at open, surfacing step, hidden-run predicate.
- **run-productions** (L6): what a run may produce: `suggest` (one basis version, `suggested`, plane-checked) and EXTRACT's proposed readings (machine-labelled, within `mints`, never extraction coverage).
- **skills** (L6): the doctrine pack an AI run works under (resident + disclosed layers, versioned by digest); holds no gate; prohibitions; four-level absence facts; action/filing/edition/wizard layers.
- **agent-worker** (L6 fleet member): the Worker that performs an AI run: deterministic control-flow table, four-level fan-out, report contract, dedup, submit/adjust, payer cascade; plan mode (PLAN_FLOW); model call to Anthropic Messages API.
- **capture-requests** (L6): the AI requests capture (never captures); the drain applies DEC-47 conduct and attribution, fetches through capture's in-process arm; credentials by scope, retry, sweep scope.
