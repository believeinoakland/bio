# Situation: cutting a release

**Status** · The product's own procedure, read whole by BOB before it cuts, signs or announces a release (the process's `roles/BOB.md` names this folder; the manifest lists each file). Bob's rulings it carries keep their source ids.

- A release is cut from the open tranche branch after the full regression (mechanics §11); what it changes reaches `main` only through the tranche's close.
- Before it is cut: the dead-end census (`rulings-product/quality.md`, K4164); the stewards' contact address named by Bob (`rulings-product/stewards.md`); the release checked as administrator and member at `/` and every screen (`rulings-product/quality.md`, K3052); the new-team rehearsal (`rulings-product/installer-accounts.md`, K4935).
- Every act of a release is BOB's without asking, and a signed cut is merged into the open tranche branch at once: `rulings-active.md` §2 ("Releases", K5293, K3217).
