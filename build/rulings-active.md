- Splitting a product module: copy, then delete, in one tranche; the new module builds by copy and merges early, then the source module's job deletes its copy and re-points; a moved id is retired as "moved to <module> R<n>", never reused (K624). - The handoff is `build/handoff.md`, replaced whole each time (K2026); it names the few rulings its successor must read, and every ruling of Bob's that sets how the work is done enters this file in the commit that records it. - Reading-set budgets: BOB's takeover set at most 250 KB; a module job's set at most 600 KB, measured by `build/plan/reading-sets.py` at each START; a set still over it is given a task digest by the job's workers (K2700). - A split keeps the old module delegating to the new one; a wording-only requirement fix with no code change is BOB's edit, never a job (K3259, K3268).
