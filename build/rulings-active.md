## 4. Operational lessons
- A live instance is reached through the environment's proxy, unchanged (Chromium `proxy: {server: HTTPS_PROXY}`); the direct route (`--noproxy`, unset proxy variables, `HOME=/opt/walk-home`) is refused by auto mode as "Containment Escape" and never tried (K4733). A live walk signs in with `JOURNEY_ADMIN_*`/`JOURNEY_MEMBER_*`; BOB debugs the running instance itself, Bob is never the tester (K3546).
- A push answered "Internal Server Error" is retried at once with `git -c http.version=HTTP/1.1 push` (K1977). `mail post` and `mail done` push the whole local tranche branch: post or move cursors only after a local merge is verified (K4683).
- Merge job branches with merge commits, never a rebase; a job branch that re-applied tranche commits under new hashes is merged only after checking it differs from the tranche state only in its own paths and record (K1991). Run the ownership check before a merge only while the job holds the tranche's tip, else against `git merge-base` (K1295). Before closing a layer, check every `job/T<n>/*` branch is an ancestor of the tranche branch (K3797).
- A job branch is moved only by `mail jobbranch --module <m>` (civicos-process `prep/jobbranch-K4385` until T51's close): no session pushes to a job branch by hand and nothing is force-pushed (K4385); a branch far behind makes `mail start` conflict (K3969).
- Before any test run, in every container (Bob, K4113): every directory with a tracked `package-lock.json` has its `node_modules`: `for d in $(git ls-files '*package-lock.json' | xargs -n1 dirname); do [ -d $d/node_modules ] || (cd $d && npm ci --ignore-scripts --no-audit --no-fund); done`. A restart empties them.
- Run `newgroup-bundle-fresh` and `fleetbundles` with `node --test --test-force-exit` (K3972); never edit `modules.json` or `order.mjs` while a bundle build runs; never stop agent-worker's test run midway (restore from HEAD; K1994); a long command runs as a session-tracked background task, never a bare `nohup` (K4207).
- Read a check's result by its own failure count, never by filtering for a word (K4668); after each merge in a layer run the words check over the layer's merged modules (K3986); each START requires an explicit test for ids that other tests already name (K874); a plane bundle breach of 32 MiB goes to Bob (K2547); measure a module's size (P6) over its own code (K2513); regenerate artifacts in the manifest's order, newgroup last (K1540).
- Read every scripted edit back (K702); LIKE/GLOB patterns on the plane stay within workerd's 50 bytes and `sql.exec` cursors are spread (K313); a table key, thrown `feature` or any string code compares is an identifier, never a `localize` sentence (K3971).
- BOB reads its `context_usage` (`get_session`; its `max_tokens` is the window, K3987) at every backstop check and before every merge ruling and writes the figure in that ruling (K4617).
- A refused doorbell is rung a minute later, never in the same step as a destructive local command (K1825). On a point already answered, wait for the job's next entry (K1172). Before restarting a QUIET job check its session is not in one long live turn (K506).
- A dropped container is caught by the tool (Bob, K4976): `RUNNING until` is at most 30 minutes ahead; `mail check` flags QUIET a RUNNING job 30 minutes past its last push; a job whose session is idle or disconnected while its record says `WORKING` or `RUNNING` is QUIET at once. The tool is civicos-process `prep/running-cap-K4976` until T51's close.
- Container images are built by the GitHub workflow `agent-runner-image.yml` (GHCR, by digest), never in a session; the project's Cloudflare token is `bio-biosmoke7-deploy` with Containers - Edit (K1898, K1985).

## 5. Standing BOB conventions
- A job never strikes a `not yet met` mark: it names the met ids and BOB strikes them at the merge (K787). A test names a requirement id at the module's interface; an id not yet met is named in a `test.todo`, never a red test or a pin of today's behaviour (K208).
- Splitting a product module: copy, then delete, in one tranche; the new module builds by copy and merges early, then the source module's job deletes its copy and re-points; a moved id is retired as "moved to <module> R<n>", never reused (K624). A new module enters `modules.json` with empty `paths` and `tests`, filled from its job's COMPLETE, and carries a membership `MODULE_ORDER` (R83) entry in the same act (K1185, K1975).
- One code, one condition, one site: the module owning an absent object provides the helper and the row; distinct conditions get distinct codes; a member-facing refusal follows DEC-83's sentence-then-remedy pattern (K446). Merge in `modules.json` order, upstream first; promotion's stamp merges last in its layer (K1965). An entry found mid-tranche for a module whose job has not started joins that job's START when small (K411).
- The handoff is `build/handoff.md`, replaced whole each time (K2026); it names the few rulings its successor must read, and every ruling of Bob's that sets how the work is done enters this file in the commit that records it. Every handoff prunes (Bob, K3559): lines no longer in force are removed, finished plans, drafts and walk files under `build/plan/` move to `build/plan/archive/`, and the handoff checks this file's count (K5012).
- Reading-set budgets: BOB's takeover set at most 250 KB; a module job's set at most 600 KB, measured by `build/plan/reading-sets.py` at each START; a set still over it is given a task digest by the job's workers (K2700). A job reads its requirements, entries, layer contract, own code, the used services its entries touch and the tests naming a requirement its entries change; its other tests are run, not read (K3271).
- Words: tests never copy a sentence people read; a test asserts the key or reads the expected text from the word table, and a wording change is a word-table edit, never a module job (K3810). Words are kept (Bob, K3930): a sentence is written once at its use as `localize(id, en, vars)` (K3943) and extracted into the word table by a build step; the table wins, code wording is never synced back. The `unkeyed` list is not counted by the check (K3944); a refusal `detail` is a sentence a member can read wherever it travels (K3985).
- Module tests at the providers' real shapes (Bob, K4990, K4993): a test never hand-builds another module's answer or a stub of its interface; it uses the provider's published fixture, produced by the provider's real code when the test runs, never stored; a `fixtures` check refuses hand-built answers (its text to Bob before it binds); the through-the-door seam test of each cause is written before its module jobs start.
- Fewer tiny-change fan-outs (K3268): a test asserts its own module's behaviour and never hand-lists another module's ops, rows or words; a split keeps the old module delegating to the new one; a wording-only requirement fix with no code change is BOB's edit, never a job (K3259).
- Citations (K3676): a rule's line cites only the latest ruling that sets it. A body over about 50 KB that BOB must review whole is read by a reading worker told the task, never into BOB's own context.
- Effort (Bob, K3269, K3294, K3518): every plan and START is shaped to spend fewer tokens. Each job's model is BOB's choice at its START, the cheapest able: claude-haiku-5-5 for test-only, wording-only and mechanical re-point jobs; claude-sonnet-5-5 otherwise; the default model only for a new module, a new provided service of more than three ids, a screen job drawing the claim or first sign-in, or a restart after a Sonnet job blocks on tests. BOB on opus at medium; every worker spawn names model and effort (haiku low for mechanical work, sonnet medium otherwise; never opus).
- Lanes (K3538, K3553, K3469, K3718): UX-DESIGN (charter includes researching dashboard-style primary entry points per functional area, K3053), INVESTIGATION-DESIGN (fold each hand-off into requirements, answer with a K; K2076), AI-DESIGN, JOURNEYS (walks), PERFORMANCE (slowness, K4351); BOB reads each `HANDOFF.md` at takeover and each backstop check, turning each defect into an entry (K3551); lanes change no code. A ruling of Bob's is posted in the same turn to every lane it touches and, when that lane's session is on BOB's account, rung (K3082, K3086).
