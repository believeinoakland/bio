4. **R77's mechanics.** A `derived-rebuildable` entry names `rebuild(scope)` and `key` (the columns naming one row). `scope` is `null` (the whole table) or a column→value map; `rebuild` answers the rows. `markStale(module, table, key)` and `readDerived(module, table, key)` take the key as a column→value map (or a bare value for a one-column key). "Until a rebuild clears it": `rebuildDerived(module, table, scope?)` replaces the held rows in scope with `rebuild`'s, in one transaction, and clears the marks in scope. The marks live in a new table of mine, `derived_stale`. `rebuildAndCompare` builds the scratch copy as a table inside a savepoint it always rolls back, so SQLite's own typing is compared, and writes nothing.
5. **R78's mechanics.** `check` is one function or a list of functions, run in order ("the table's checks in registration order"). A check passes with `null`/`undefined` and refuses with an object carrying a non-empty `code`; anything else, a promise or a throw is `STORE_GATE_FAILED` (fail closed). Registering for a table another module declared, or `storeGate` called by a module that is not the table's declarer, is `STORE_GATE_MALFORMED`.
6. **R79's mechanics.** `key` is a non-empty column→value map, every column matching. An empty key, or one naming a column the table lacks, matches no row (`EXPUNGE_NOTHING`). `module` must be the table's declarer, else `EXPUNGE_NOT_DECLARED`. A machine `by` is a `token:` identity (the lease's convention). `court_order` without `order`, or `lawful_demand` without `demandKind`, is `EXPUNGE_GROUND_UNKNOWN`. Tombstones live in a new table of mine, `tombstones`, exempt from purge; `tombstones({table, after, limit})`'s cursor is the tombstone's sequence number.
7. **R21's defaults.** The default `sight` of a name-only `declarePurge` entry ("bundle when the table is keyed to a bundle") is decided when `declaredTables()` is read (the table's `bundle_id` column, as purge decides it), since a table may not exist yet at declaration. `version_chain` is a boolean.
