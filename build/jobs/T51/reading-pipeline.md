### G68 · a tick reads its piece, not the object

**(1) Cause, as the plan has it, and what the fix does.** `readInner` read the whole object (`bytesOf`) on every tick, and then for a CSV `entry.text` decoded all of it (17 MiB), for a text `new TextDecoder().decode` all of it (12 MB), and for a PDF `extractPdfRange` re-parsed all of it. Now (index.mjs line numbers at the tip of this job):
- **A cursor of kind `w`** (new, 1585-1876): the first piece (and a piece asked by a cursor of the old kind, `t` or `u`, which is still read as it was and is moved on to a window) hands on the byte offset of the next piece in the object and what a window cannot know (grain; the sheet's last column and whether a row was cut; bytes already read; for a CSV the head's end and record count, the row, the line and the line-in-record the next block begins at). A later piece (`windowTick`, dispatched in `readInner` before `bytesOf`, 2320) asks the evidence store for its window alone (`rangeBytes`, record-core R88's ranged `get`; a store that ignores the range is cut here).
- **Text** (`textWindowCursorOf` 1644, `textWindowTick` 1655): made for a capture read as text that is not HTML, valid UTF-8, held whole under the document's digest (`bytesOf` now says `whole: true`). The window is decoded, cut to the runs it holds whole (`completeRunsEnd`), and `textPiece` (the very function the first piece uses, with the grain given) cuts the units; a window with no whole run, or whose runs do not fill the piece, is doubled. The cursor is checked: digest, object size (from the store), a character start, white space before it.
- **CSV** (`csvWindowCursorOf` 1724, `csvWindowTick` 1764, `scanBoundaries` 1705): made for csv-reader's output in UTF-8, US-ASCII or an undetermined encoding, longer than the head its signatures read (1 MiB + a BOM), whose sheet is named by row. The record boundaries are found by a quote-aware scan (a doubled quote is two turns; CR, LF and CRLF end a record outside quotes) that the tests hold to csv-reader's walk.
- **What is not windowed, and reads as before** (the object whole each tick, as the old cursors do): an HTML page (its visible text is judged over the whole markup), a text that is not valid UTF-8, a CSV in UTF-16, a CSV not longer than the head, every other format, an object not held whole, a store that cannot answer a range (the cursor is not made: the first piece probes it).
