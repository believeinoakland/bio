## agent-steps (own requirements)

Status: in force since T51-45 (K624); copied from `agent-worker` (its R119 delegates); R1-R42 moved from there, R5 and R43-R49 new. Not yet met (T53): R2, R14, R23, R26, R34, R47, R48, R50-R57. None retired.

Purpose: performs an AI run's steps for the Worker shell: reads the run from the plane, holds it to its account and pack, walks `agent-harness`' table (plane calls, model turns and level sub-sessions when a model is handed in), ticks the plane after every step, closes the run through the plane; decides no step, words none of the shell's refusals, writes nothing itself, keeps nothing between calls; holds the shared readers (plane answers, file text for a model, loadable pack layers, the model half).

Terms: a **refusal** is `{ok:false, reason, code, detail, worker, …extra}`, `reason` = `code`, answered by the shell's `host.refusal`; the **plane** is reached only through `host.askPlane`; a plane answer is **silent**, **refused** or a **result** (R44); a **segment** is one `driveHarness` invocation, walking the table until the run ends or a segment bound (meter turns or bytes, wall `deadline`, `maxSteps`), the run going on after a segment bound.

**`driveHarness(host, env, {runId, store, credential, judgements, maxSteps, account, model, deadline, progress, preflight})`** answers `{ready: true}` (`preflight`, after R1-R5 pass), `{refusal}` (a response from the host's functions) or the segment's result `{mode, trace, passes, ended, logged, submitted, target, refusals, adjusted, verbatimResubmits, resumedFrom, logRefused, presentUnbacked, fanout, reportsTaken, reportsRefused, citationsReread, holdings, budget, segmentStopped, segmentEnd}`, from which the shell assembles `agent-worker` R28's answer.
