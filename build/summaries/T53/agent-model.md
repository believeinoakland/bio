## agent-model (own requirements)

Status: in force, reviewed (K1505, K1599); split from `agent-worker` (R1 its R40 amended, K1502). Size (P6) under 4,000.

Purpose: how a model turn reaches the AI provider an account names (today Anthropic's Claude only). Given the account reference serving one member's act (her own, a project's or the group's API key; K1755, N812, D34), it sends a conversation's turns to the Messages API (API key) or to Claude Code in `agent-runner` (subscription), returns each turn's outcome and `usage`, and keeps the segment within its turn and byte bounds. Holds no credential: the reference arrives per call, never kept.

Terms. **Account reference**: `{kind: "apikey", key}` or `{kind: "signin", member}`, a member's own or (apikey only) a project's or the group's, with `level` (`member`, `project`, `group`) as `credentials.accountFor` answers (its R35); `signin` carries no secret. **Meter**: `segmentMeter({turnsBound, bytesBound})`'s plain object. **Outcome**: exactly one of `{result}`, `{silent: {detail}}`, `{refused: {status, type, message}}`.
