Purpose: the instructions an AI run works under, the doctrine pack. It renders, from what the plane publishes and from the modules that enforce each word, a resident layer every run holds from its first token (objective, machine/member boundary, four-level rule, absence vocabulary) and progressively disclosed layers loaded when needed (judgement clauses, prohibitions, deployment order, vocabularies, acts, bounds, refusals, wizard scripts and their authoring). The pack's version is derived from what was rendered, so runs under different instructions are distinguishable. It holds no gate: every fence it names is code elsewhere, and a model ignoring every word would get past nothing (§14b.4). Its one refusal: a run must name the version it runs under.
