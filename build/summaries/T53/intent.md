Purpose: Intent holds what the group is trying to achieve and turns it into checkable work (Content Framework §12): aspirations (standing, never close, set priority), goals (bounded pursuits that close) and objectives (a project's aim, with a satisfaction condition the record is measured against). Progress is computed from the record, never reported; its gaps are the work list. Unasked-for findings arrive as proposals; only a member's act adopts one, opens a question from it, or sets it aside with a recorded reason (the discovery loop).

Terms: aspiration `{id, scope, owner, statement, entities, progressions, state, author, at}`, `scope` `group`|`project`|`member`, `owner` the project or member id (none for `group`), `state` `held`|`retired`. Goal `{id, statement, bounds, aspiration, objectives, state, closed_reason, author, at}`, `state` `open`|`closed`. Objective: a project's `objective` text with an optional condition `{progression, entity, relation, filter, required: {grade, stages}, satisfied: {share}}`. Proposal: `{key, source, kind, grade, basis, instances, surfaced_by}`. Machine: a credential with no person behind it.
