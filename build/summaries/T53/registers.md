## registers (own requirements)

Status (K5808): New module, BOB's (K4403 (1); layer 5, after `workbooks`); every requirement not yet met (T53). From N1259-b (R1–R46), N1259-d (R61–R72, guardrails) and K5730 (R73, content's row context), `build/plan/beta/capabilities/`; draft ids kept (R47–R60 other modules', unused); op door names BOB's. 59 ids; none retired or moved.

Purpose: holds the public registers a team imported, whole or in part, by fixed steps with no AI: lists known and team registers; plans an import (prefilled filter, delta, time estimate); runs it in the background as resumable slices; keeps and searches rows and their source captures; cites a row as a labelled extract; compares two imports; keeps a project's stated interest as a change-watching filter. Holds no fact, score or judgment about anyone.

Terms: *Held rows*: kept cells of rows in visible imports. *Visible*: the viewer may see it. *Scope*: `project` (the project's sight) or `team` (a pre-read; the team's). *Interest*: a filter a member attaches to a project and a register. *Slice*: one bounded unit of an import's work. *Machine*: a machine author, viewer or credential. `→`: answers. Refusal codes are drafts.

## Used services

Layer 1 Purposes. `register-readers.md`: reads a register file into rows under a definition, filters, drops unkeepable columns before any other code sees a row, writes the reduced copy; no store, clock, network or AI. `jurisdictions.md`: every local fact as profile data; no other module names a place. `civil-time.md`: the one pure civil-time engine. `id-spaces.md`: judges shared identifiers. `record-grammar.md`: ids, types, front matter, canonical JSON, the one SHA-256. `runtime-limits.md`: runtime facts and every reader's ceilings. `setup-words.md`: the word list as frozen data. `test-support.md`: test sandbox, generators, alarm double.

`record-core.md`: owns the record's storage (ids, leases, append-only history and manifest, purge); every storing module writes through it.
