## publication (own requirements)

Status: in force (K102); split five times for size (K617, K651, K1024, K1332, K1505, K2438), moved ids retired here. Every requirement met (K2011) except R30 (D-246) and those marked not yet met. Size (P6) under 4,000 lines of code.

Purpose: publication is the one irreversible act: what the group stands behind leaves the instance, content-addressed and signed, so a stranger can verify without this instance that the group said what it claims and rested it on what it says (Publication §1). This module is the published record: every case document (unsigned and signed), the published projection, which cases a finding serves, and a member's choice of attribution. `ratification` and `case-authoring` write through it. The grammar is `case-grammar`'s, the public read `public-read`'s, a project's stage `project-stage`'s, the export `corpus-export`'s; each reads its tables only under R40; every table and write stays here except `export_log` and `case-carriage`'s two held-materials tables (called inside this module's commit).

Terms: a **case** is one project's production over findings (`load_bearing` or `supporting`); an **edition** one numbered, separately signed version; the **case document** its signed artefact; a **pin** a member's `bundle_sha` as named; the **published projection** the `published_*` tables, `cases`, signed documents and the published bucket; a **stamp** (`author`, `viewer`, `by`, `deliveredBy`, `secretSha`, `bySecret`) is the control plane's. Refusals name `reason`, and `check`, `code`, `translation` with a row.

## Used services

retrieval (`build/requirements/retrieval.md`): runs the query language over the record, keeps each bundle's projection and index, answers searches with which absence is true, and builds no ungated SQL.

record-grammar (`build/requirements/record-grammar.md`): the shared grammar (ids, types, front matter, canonical JSON, actor identity, grades, the one SHA-256); no store, network or clock.

signatures (`build/requirements/signatures.md`): builds and verifies SSHSIG and RFC 3161 statements and the release signer's tool; no record, stored key, clock or network call.

record-core (`build/requirements/record-core.md`): owns the record's storage: ids, leases, append-only history and manifest, purge; no member, fence or promotion path.
- record-core R60 · `textAtSha(bundleId, sha)` returns the inline text of the bundle's `bundle.md` whose SHA-256 is `sha`, from the live file or any historical snapshot, from this module's tables alone; `null` when either argument is absent, no such text is held, or the file is held only as a blob. Never throws (`publication` R2, `ratification` R3; K94, N69; K203).
- record-core R21 · Tables declared once through `declareTable(module, entries)` with classes `purge`, `expunge`, `export`, `sight`, `derive`, `version_chain` (missing or unknown: `TABLE_CLASS_MISSING`/`TABLE_CLASS_UNKNOWN`); `declarePurge(module, tables, {exempt?})` is its default form (`exempt` when listed, else `clear`); declared twice or by two modules `TABLE_DECLARED`.
- record-core R46 · A declared table is a name keyed by `bundle_id`, or `{name, keys, whole}`; the same fields sit beside `declareTable`'s classes.
- record-core R32 · `transact(fn)` runs `fn` as one transaction over the whole store: a throw or a refusal (`ok:false`) rolls back every row written inside it in any module's tables, and no id allocated inside is spent; a nested call joins the outer (a savepoint: its throw or refusal rolls back its own writes and ids, the outer decides the rest). Rethrows what `fn` throws, after rollback.
- record-core R47 · `stampInstant(precision, when?)`: UTC ISO 8601, `"second"` `YYYY-MM-DDTHH:MM:SSZ`, `"millisecond"` `YYYY-MM-DDTHH:MM:SS.sssZ`; another precision throws.
