## wizard-scripts (own requirements)

### Public

Purpose: the library of wizard scripts (step lists a wizard walks a member through on real screens): the Civicsmith library (shipped, read-only to groups) and each group's own (versioned, never edited, approved by a project owner, widened by an administrator, retired never deleted). Holds the checks, serves scripts with no AI credential and no key, keeps unattributed daily tallies. A machine proposes, never approves. A script never says or submits for a member; a step's draft is labelled and is the member's words only when kept or edited by the member (K1364 B3). The runner and screens are the interface's.

Terms (§ Provides): version `state` is `draft`, `submitted`, `approved`, `updated` (an approved version a later approved one follows) or `withdrawn`. A script is retired when withdrawn whole (R9). A version is offered when it is the latest `approved` of a script not retired and not `broken` (R13) and the viewer may see it (R20). Refusal shape `{ok:false, reason, code, check, translation, ..}`, naming the step where R12 says so. R10, R11, R17, R26 write nothing.

Registration: `wizardRegister({screens, ops, machineRefused, machineDrafts, irreversible, library})` (in-process; `store-assembly` R17).

- **R1** Script `{id, origin, scope, name, start, required, versions}`: `id` opaque `WIZ-`; `origin` `civicsmith` | `group`; `scope` `{project}` or `group` once R7 widens; `name` 1-200 chars one line (`WIZARD_NAME_REFUSED`); `start` the first step's screen; `required` true only for `civicsmith`. Version `{script, version, steps, sha, state, author, contributors, derived_from, approved, ended}`, `version` from 1, `sha` SHA-256 lowercase hex of the canonical steps, steps and `sha` fixed once past `draft`. `based_on`: `null` or the `<script>@<version>` copied from (R3), set once.
- **R2** Step `{screen, act, what, why, draft?, via?}`: `act` null or an op the registry lists for `screen`; `what`, `why` 1-300 chars; `draft` one of `{text}` (<= 4,000 chars), `{template}` (a version `filing-templates` R25 offers), `{machine:<op>}` (a registered machine-draft op), always answered labelled with its kind. A step never acts: a draft is placed, never submitted; no step submits, signs or files. `via` = another script's `id` (side trip): the member goes through its steps as R11 offers them and returns to the step left; R15 counts its use as that script's; following is the runner's; this module holds and checks `via` (R12), answers it (R11, R21).
- **R3** `wizardDraft({project, name, recorded | from | copy, author, viewer})` (`op=wizarddraft`) -> `{ok, script, version, sha, state:"draft"}`. `recorded` is `{screen, act}` pairs only (any other key: `WIZARD_RECORDING_CARRIES_VALUES`); `what`/`why` empty until revised (R4). `from` = a proposal (R5) or an approved version the author may see. Blank start needs a live editor grant (R8). Order: `MACHINE_CANNOT_DRAFT_WIZARD`; `NO_SUCH_WIZARD` (`from` absent or not visible); `WIZARD_SCOPE_REFUSED` (not a joined participant, `membership` R54); `WIZARD_EDITOR_NOT_GRANTED`; `WIZARD_RECORDING_CARRIES_VALUES`; `WIZARD_NAME_REFUSED`. `copy: <version>` (any approved version the author may see, R20) creates a NEW script `origin:"group"`, `scope:{project}`, `required:false`, `based_on` that version, first draft = its steps (pairs count as recorded pairs); never a version of its base, the base unchanged and offered; approved like any group wizard (grant, R6, R12, R7); a copy of a required script never replaces it. A bad `copy` = `NO_SUCH_WIZARD`, in `from`'s place.
- **R4** `wizardRevise({version, steps, adopt?, author, viewer})` (`op=wizardrevise`): new revision of a draft, earlier revisions kept with author and time.
