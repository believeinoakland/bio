# registers — requirements

**Status** · New module, BOB's (K4403 (1); layer 5, after `workbooks`); every requirement not yet met (T53). From N1259-b (R1–R46), N1259-d (R61–R72, guardrails) and K5730 (R73, content's row context), `build/plan/beta/capabilities/`; draft ids kept (R47–R60 other modules', unused); op door names BOB's.

## Public

### Purpose

Holds the public registers a team imported, whole or in part, by fixed steps with no AI: lists known and team registers; plans an import (prefilled filter, delta, time estimate); runs it in the background as resumable slices; keeps and searches rows and their source captures; cites a row as a labelled extract; compares two imports; keeps a project's stated interest as a change-watching filter. Holds no fact, score or judgment about anyone.

### Provides

**Terms.** *Held rows*: kept cells of rows in visible imports. *Visible*: the viewer may see it. *Scope*: `project` (the project's sight) or `team` (a pre-read; the team's). *Interest*: a filter a member attaches to a project and a register. *Slice*: one bounded unit of an import's work. *Machine*: a machine author, viewer or credential. `→`: answers. Refusal codes are drafts.

**Planning an import: the filter and the delta**

- **R8** (T53; N1259; K4403 (2); `register-readers` R6, R8) **`registerFilter({register, project?, viewer})`: the filter, prefilled from the project and said so.** Visible `project` → `{ok, filter, prefilled: true, basis, left_out, interest?}`: `filter` by `register-readers.prefillFrom` over the project's visible named subjects and identifiers (`entities.subjectsOfProject`, `entities` R74), e.g. subject organization, filer id, period → `organizations`, `filer_ids`, `date`; `basis` each criterion's source fact; `left_out` criteria the register cannot apply; `interest` the project's saved interest on it, if any (R32). Unseen project `NO_SUCH_PROJECT`; no project or no usable facts → `{}` (whole register). Checked by `validateFilter` (an edit validates or gets its code), not saved: a proposal to edit. Nothing inferred from project text (address facts, notes add nothing); a person or organization enters only as a subject the project names.

- **R9** (T53; N1259; K4403 (2); K4405 (6)) **`registerDelta({register, filter, scope, project?, budget_ms, viewer})`: what an import would add, before any is brought in, each figure counted or estimated.** → `{ok, new_rows, already_held, bytes_in, bytes_stored, seconds, shelf, source_date, probe, timed_out}`. `already_held`: index rows matching the filter in visible imports. `new_rows` `{value, basis}`: `counted` only if `acquisition.probeRegister` (`acquisition` R128) counted this same filter and the definition says `append_only` (source rows less `already_held`, floor 0); else `estimated` by `register-readers.estimate` and the last import's selectivity (rows kept per row read), e.g. with a name the count cannot apply; or `not_stated`. `bytes_in`: `stated` by the probe or sum of pieces, else `not_stated` (e.g. no `Content-Length`). `bytes_stored`: estimated from rows and the last import's bytes per row, else the definition's sample. `seconds` `{value, low, high, basis: "estimated"}`: `bytes_in` times the median of the last three imports' `took_ms` per byte, else `THROUGHPUT_DEFAULT` (M-R7); never `counted`. `shelf` `{free_bytes, would_use_pct, warn}` from the storage port (R22). Governed probe requests only (no body); writes and records nothing; at `budget_ms` (default 1,200) stops with `timed_out: true` and what it has, never a guess. Refusals as `importStart` (R3-R5, `FILTER_*`).

- **R10** (T53; N1259; K4405 (6); DEC-411) **An estimate is recorded against its outcome.** An ended import records `took_ms`, `bytes_in`, `rows_in` for R9 (after three of different speeds, the median rate's arithmetic); a failed one contributes none; with none held the constant is used and `basis` says so.

**The import**

- **R11** (T53; N1259; K4403 (2); K4405 (3); K1449, K1492) **`importStart({register, filter, scope, project?, author, viewer})` (`op=registerfileimport`, new; `registerimport` is `events` R38's other act, a machine's, `op-declarations/index.mjs:238`; scope `team` is the pre-read, `op=registerpreread`): a member's act that queues a background import, fetching nothing.** Refusals in order, writing nothing: machine or absent author `MACHINE_CANNOT_IMPORT_REGISTER`; `NO_SUCH_REGISTER`; `REGISTER_NOT_IN_ALPHA` (R3); `REGISTER_NOT_MEASURED` (R4); `member_act_required` (R5); `FILTER_*` (`register-readers` R6); scope `team` by other than an active administrator `NOT_AN_ADMIN` (K4405 (3)); scope `project` without a visible project the author takes part in `NO_SUCH_PROJECT`; `IMPORT_QUEUE_FULL` when `MAX_ACTIVE_IMPORTS` (`runtime-limits` row, 2) are queued or running in this instance. Same register, filter fingerprint and scope queued or running → `existed: true` with it. Else it writes `{id, register, filter, filter_fingerprint, scope, project, state: queued, author, queued_at}` (a `team` import is a resource: every member's search includes its rows, every project's delta counts them held), calls the `onImportQueued(module, fn)` listener (one per module, `membership.listenerRefusal`, as `following` R19; `scheduler` registers its `arm`, `scheduler` R9, R23) so an idle instance arms its alarm, and answers within the act's time, no request, never waiting for a byte.

- **R12** *(not yet met: T53)* (T53; N1259; K4403 (2)) **The import runs as resumable slices on the scheduler's alarm and ends with an uninterrupted run's rows.** `importDue(now)`: an import is queued, running or retrying and the host not paused; `importWake(now)`: the earliest due instant, else null; `importTick(now, budget, host)` claims the oldest due import under the host's epoch (a retry never runs a slice twice; `host` a parameter as `following`'s, `monitoring` R21, R30, not imported), runs at most one slice (bounded by `budget_ms` and bytes: `register-readers`, `acquisition.streamRegister` R125–R127), records progress, → `{import, state, progress, done}`; a paused `host`: no slice, `paused: true`. States: `queued`, `fetching`, `reading` (reducing, indexing), `indexed` (done), `failed` (`reason`, `retries`), `paused` (`reason` `member`|`shelf`|`host_paused`), `stopped`. A restart between slices re-derives from the import's table and cursor; a failing slice retries up to 3 times with growing delay, then `failed` with its reason; a new `importStart` makes a new import. Test: R67 (G9), killed between each pair of slices of a 1M-row fixture (row-table digest, counts, segment digests).

- **R13** (T53; N1259; K4403 (2)) **`importStatus({import, viewer})`, `importSet({import, action, author, viewer})`: progress, and pause, resume or stop.** `importsEnded({after, limit})` lists for the queue imports finished, stopped or failed (not refreshes). `importStatus` → state, pieces (each `pending|reading|done|failed`), `progress` `{bytes_in, rows_in, rows_out, segments_stored, percent?}` (`percent` only for `stated` bytes), `started_at`, `finished_at`, `took_ms`, `source_date`, `reduction` (R15), `reason`, `retries`; hidden or absent → `NO_SUCH_REGISTER_IMPORT`. `importSet` `pause`|`resume`|`stop`: the starter or an active administrator (else `NOT_YOUR_IMPORT`; machine `MACHINE_CANNOT_SET_IMPORT`). Paused: the next tick runs nothing; `resume` continues from the cursor; `stop` ends it, keeps what was brought in searchable and says so (`stopped`, counts); stopping twice → `existed: true`; `resume` on `stopped` → `IMPORT_STOPPED` (start a new one).

- **R14** *(not yet met: T53)* (T53; N1259; K4403 (2)) **Every import is a capture with its source and date.** Each segment of each piece is filed through `acquisition` and `promotion` (`acquisition` R125, R133), the import as authority; the import row binds each piece to its segments and captures and states per piece: source address, retrieved-at, the source's stated date (`Last-Modified`, the dataset's `updatedAt` or the file's date, else `not_stated`, never retrieval time), the original's fingerprint (`covers` whole file or named member). `imported_at` = oldest piece's retrieval; `source_date` = oldest piece's stated date. Re-importing the same bytes shows `existed` captures and its own date.

- **R15** (T53; N1259; K4403 (5); K1485; DEC-408) **The reduced copy on arrival is stated, never silent.** `reduction` = `{kept_columns, dropped_columns: [{name, why}], withheld_cells, rows_in, rows_out, rows_undetermined, original_fingerprints, reason: "reduced under K1485"}`, names and counts only (no value in import row, status, listing or answer); listing, status and every extract state "phone and address columns are left out as it arrives" by key (`register.reduced`). No contact columns → no contact role dropped.

- **R16** (T53; N1259; K4403 (2)) **Importing is mechanical: no AI call is made.** Neither `registers` nor `register-readers` lists an `ai-*`, `agent-*` or `skills` module in `Uses`; a full cycle (plan, delta, import, search, cite, compare, interest, refresh, watch change) makes zero AI-boundary calls, `ai-use` ledger and AI counters unchanged. Test: R68 (G10).

- **R17** (T53; N1259; K4403 (2)) **A retry or a second run never duplicates a row or a capture.** Rows are written by `(register, row_key, content_hash, sight scope)`; segments are content-addressed; a repeated slice writes nothing the first did (one index row per key, one object per segment digest); a changed row writes one more version.

- **R18** (T53; N1259; K1492 (1), (4)) **An import is polite and attributed.** Every slice request is `acquisition`'s (governor pacing, the agent naming the instance and purpose `register`, the definition's hosts only); `HOST_COOLING_OFF` pauses the import (`host_cooling`), resuming after `retry_in_ms`, not a failure.

- **R19** (T53; N1259; K1489; K4403 (2), (7)) **An import is seen as its scope is: a hidden project's import, its filter and its rows stay inside it.** A `project` import and its segments take the project's sight (`membership`'s fence); a `team` import the team's. No list, count, delta, search, compare, status, extract, queue item or error names, counts or lets one infer an import, filter or interest not visible: `already_held` counts visible rows only; a row first stored in a hidden project's import is stored again (own version) by a team import, not shared. Test: R70 (G13).

- **R20** *(not yet met: T53)* (T53; N1259; K4403 (2); K4354) **An import is never in the way of the member's screens.** Slice transaction batches are bounded so no write holds the object's one worker beyond `SLICE_TX_MS` (draft 100 ms, set with PLATFORM); a slice yields between batches; no read op waits for a slice. **Storage**

- **R21** *(not yet met: T53)* (T53; N1259; K4403 (2) "storage designed for large datasets"; K1727's pattern; restated K5817 from REGISTERS #1's report) **A row version is stored once per scope; a re-import adds only what is new or changed; every version seen is kept (storage S2 behind the port, K5530 F4, until M-R3).** Per sight scope, a row version's kept cells are held once in the row store (where searches read them, R24) and its bytes once, in the reduced segment of the import that first saw it; the index holds the row's terms (`register-readers` R5), `row_key`, content hash and a pointer (segment, row number, byte range). A later import of the same register and scope writes index rows, cells and segment bytes only for a key not held or with a changed hash (identical: none beyond the descriptor), recording the rest `unchanged`, and its capture (R14) holds only those rows (`acquisition` T53-630); an older version stays addressable by its import (`rowOf`). Another scope stores its own copy (R19).

- **R22** (T53; N1259; K4403 (2)) **The row index is a rebuildable, bounded table behind one storage port.** Declared to `record-core` with `derive: derived-rebuildable`, `from` (segment-descriptor table, record-core R77) and `rebuild(scope)` recomputing it from stored segments; `rebuildAndCompare` is `{same: true}` after any import sequence, `{same: false, first}` on a corrupted row. Index and segment rows are reached only through one port (`rowStore`: put a delta, find by terms and range, get a row, list by key range, count, free bytes, rebuild); one contract suite passes unchanged on each implementation (in-memory; the team object's SQLite). All tables declared: index `purge: clear`, `expunge: tombstone`, `export: never`, `sight: source`; import and interest rows `export: yes` (descriptors, R41); proposals, own definitions `sight: group`.

- **R23** *(not yet met: T53)* (T53; N1259; K4403 (2); K4354) **Storage is bounded in memory and in time, and refuses before it overruns.** A slice holds at most `SLICE_MEMORY_MB` (from M-R7; draft 32 MB) beyond the reader's two windows. Before writing, a slice asks the port for free bytes; if the import's estimated stored bytes would pass the object's warning mark (Settings screen's 70%) it pauses, reason `shelf`, with the figures; an administrator's resume is refused while it would pass 90% (`SHELF_NEARLY_FULL`); nothing is partly written. Point lookup and range query time does not grow with imports held (an index, not a scan), shown by M-R3 at (e) §3's sizes. Test: a port reporting 5% free pauses a large import; a 1M-row index answers `rowOf` and a one-criterion page within 1,500 ms on the test copy.

**Search, rows, citing and comparing**

- **R24** (T53; N1259; K4403 (2); K1484, K1468, K1492 (6); T52-DEC406 §1 I4) **`searchRows({scope, name?, organization?, amount?, date?, filer_id?, form?, limit, after, budget_ms, viewer})` (`op=registersearch`): rows by person, organization, amount and date, from held rows only.** `scope`: `{register}` (its visible imports), `{import}` or all registers; criteria `validateFilter`'s, alone or together (a name matches tokens in any order, `register-readers` R5); `limit` 1–200, default 50; `after` an earlier page's opaque `next`; `budget_ms` default 1,500, max 10,000. Never fetches, calls `entities` or resolves a name; creates no entity or link; rows as written: `{import, register, row_key, src_row, cells, imported_at, source_date, version, cited, use_limit?}`, by date descending (undetermined last, not coerced), then `row_key`; pages join to the unpaged list. `matched` exact to 10,000, else `capped`. Every answer names the imports searched with `imported_at`, `source_date`. Refusals, writing nothing: `NO_SUCH_REGISTER`, `FILTER_*`, `SEARCH_BAD_LIMIT`, `SEARCH_BAD_BUDGET`, `BAD_CURSOR`. Test: `budget_ms` 10,001 refused, 10,000 served; a 5-import fixture; 130 rows paged by 50 equal the unpaged 130; R62 (G2).

- **R25** (T53; N1259; T52-DEC406 §1 I4; `retrieval`'s absence levels) **A search that finds nothing says where it looked; one stopped by its budget never says nothing was found.** No match: `absence: {level: "import", imports: [{import, imported_at, source_date}]}` and the design's "not in this import (source date …)", never "does not exist"; no import held for the scope: `no_import_held`. At `budget_ms`: rows found, `stopped: {reason: "time"}`, `more_may_exist: true`, no `absence`; nor with matches.

- **R26** (T53; N1259; K1492 (6)) **Searches are not logged.** No query text, criterion, count, result, or member id against one, is written anywhere (a table, observation log, tally, error, log line, response header included); use counts, if kept, are unattributed. - **R27** (T53; N1259; K4403 (3); K1484; 11 CFR 104.15) **Rows of a register with a data-use limit carry the limit and cannot be listed out.** A `searchRows`, `rowOf`, `citeRow` or `compare` answer with a row of a `use_limit` register carries `use_limit: {key, citation, text_key}`; its search needs a criterion (`NO_CRITERIA`), at most 1,000 rows (the 1,001st: `RESULT_CAP`); no op returns rows as a file or unbounded list; nothing in the module sends a row to a recipient. - **R28** (T53; N1259; K4403 (4)) **`rowOf({import, row_key | src_row, viewer})` and `citeRow({import, row_key, author, viewer})` (`op=registerrowcite`): read a row; cite it as a labelled extract.** `rowOf` → kept cells, `row_key`, `src_row`, segment sha and extent, `content_id` or null, original's fingerprint, dropped column names, `imported_at`, `source_date`, other imports' versions of the key, `use_limit`; absent or hidden → `NO_SUCH_REGISTER_ROW`. `citeRow` (member; `MACHINE_CANNOT_CITE_ROW`) mints through `content` (content R63) over the row's extent → `{content_id, extract}`, `extract` `{register, file, reduced_sha256, original_sha256, original_covers, source_date, imported_at, src_row, kept_columns, dropped_columns, label_key: "register.extract"}` (fingerprints = the segment's hop; id recomputes by `contentIdFor`, differs per import); again → `existed: true`, same id; tombstoned → `ROW_REMOVED`.

- **R29** (T53; N1259; K4403 (2); `following` R11) **`compare({import_a, import_b, viewer})`: rows added, removed or changed between two imports of one register, never a finding.** By `row_key`: `added`, `removed`, `changed` (each `{key, field, before, after}`). `removed` only if both had the same filter fingerprint and the later read its source to the end; else `possibly_removed`. `row_key_basis: content`: a change is a removed plus an added row, never `changed`. **Removal, the interest and the watch**

- **R30** *(not yet met: T53)* (T53; N1259; K1493; `record-core` R79; `people` R12) **`rowExpunge({register, row_key, ground, reason, order?, demandKind?, author})`: a removal leaves a tombstone and no byte of the row.** Active administrator only (`NOT_AN_ADMIN`; machine `MACHINE_CANNOT_EXPUNGE_ROW`); `reason` required authored text (absent or blank: `ROW_EXPUNGE_NO_REASON`, written nowhere, row stays; op-grades R55); grounds K1493's (`unlawful`, `confidential`, `court_order` naming the order, `lawful_demand` with a `demandKind` the active profiles list; else `EXPUNGE_GROUND_REFUSED`, `DEMAND_KIND_UNLISTED`, `people` R12). - **R31** (T53; N1259; K1493) **A re-import never restores a removed row.** A tombstoned `row_key` is skipped on every later import of that register, counted `tombstoned`; the corpus export carries the tombstone, not the content (`corpus-export` R7, R9, which carry any declared table).

- **R32** (T53; N1259; K4403 (2), (7); K4405 (1), (5); K1484) **`interestSet({register, project, filter, watch?, author, viewer})` / `interestOf` / `interestForget` (`op=registerinterest`): a project states the filter its watching looks for; nothing is inferred.** A member of a visible project (else `NO_SUCH_PROJECT`; machine `MACHINE_CANNOT_STATE_INTEREST`) attaches a validated filter to project and register; every version kept with who and when, in the project's sight (R19). `watch` defaults true, requested only if `autoWatchable` (`register-readers` R7); with a name or organization the interest is saved (`watch: false`) and `watch: true` refused `INTEREST_NOT_WATCHABLE`, naming that names are re-checked by a member's act (K4405 (1)). `onInterest(module, fn)`, once per module (`membership.listenerRefusal`, as `following` R19), is called once after the act's transaction with `{interest, watch}` so `following` creates or ends its watch (forgetting ends it; history kept). - **R33** (T53; N1259; K4403 (7); K4405 (1); K1449; K1492) **`refreshImport({interest, now})` (for `following`) refreshes a watched interest under the member's standing statement; `registerRefresh` is the member's own re-check.** `refreshImport` starts an import of the interest's register and filter for its project, `reason: "watch"`, `on_behalf` the interest's author, only if: `gate` is `none` (else `member_act_required`), the filter is `autoWatchable` (else `REFRESH_NEEDS_MEMBER`), the host is not paused, the phase allows, and `acquisition` says the source changed (`sourceChanged`, `acquisition` R129, e.g. a moved `Last-Modified`; else `REFRESH_UNCHANGED`, no body fetched).
