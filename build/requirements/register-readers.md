## Public

### Purpose

Reads the bytes of a public register file into rows under a definition, filters them by a team's criteria, drops the columns that must not be kept before any other code sees a row, and writes the reduced copy that is stored. It touches no record, store, clock or network, and calls no AI.

### Provides

`readRows`, `listMembers`, `streamZipMember`, `reduce`, `contactShape`, `indexTerms`, `validateFilter`, `matches`, `autoWatchable`, `filterFingerprint`, `prefillFrom`, `createReducer`, `estimate`. Terms: a **definition** is profile data (or a team's own, validated alike by `jurisdictions` R128) saying how a file is read; a **piece** is one file, zip member or table; a **filter** is the closed criteria for rows to keep (R6); a **reduced copy** is only the kept columns of only the matched rows, canonical, the original never stored (K4403 (5), K1485); an **import** is one run bringing a register in, whole or by a filter.

- **R1** (T53; N1259; K4403 (2)) **`readRows(source, definition, piece, opts)` reads a delimited file as rows, streaming.** `source` is an async iterable of `Uint8Array` chunks (any sizes); `header` (opts) holds a separate header file's bytes when the piece's `header_from` names one. It yields `{row_no, key, cells}` in file order, `row_no` the 1-based number of the data row (the header excluded), `cells` a map from the definition's column names to decoded text, `key` the `row_key` columns joined by a unit separator (or, for `row_key_basis: content`, the kept cells' digest plus the occurrence number). Delimiters comma, tab and pipe; double-quote quoting with doubled quotes and line breaks inside quotes; CRLF, LF and a final line without a break; encoding by BOM (UTF-8, UTF-16) else UTF-8, else windows-1252, stated per piece as `encoding` and `assumed`. Memory is bounded by two windows plus one row. A data row whose field count differs from the header's is not yielded as a row: it is yielded as `{row_no, undetermined: true, why: "field_count", fields, expected}` and counted, never padded, cut or coerced; a quote left open at the end is `why: "unterminated_quote"` with the row it opened on. A header that lacks a column the definition lists is `{ok: false, why: "column_missing", column}` before any row. Test: comma, tab and pipe fixtures read to the same rows; a row split at a window edge, or a byte either side, reads whole; a ragged row is `undetermined`, counted, and the next row intact; a separate header file supplies the names; a 200 MiB stream reads under a 64 MB heap cap. Control: an unragged file's rows equal `csv-reader`'s cells.
- **R2** (T53; N1259; K4403 (2); K1852) **A zip is read by its directory and one member at a time.** `listMembers(range)` takes `range = {size, read(offset, length)}` (a source that honours ranges) and answers `{ok: true, members: [{name, method, compressed, uncompressed, offset, crc32}]}` read from the central directory, ZIP64 included (a member over 4 GiB, a directory with more than 65,535 entries), or `{ok: false, why}` (`not_a_zip`, `zip64_record_invalid`, `directory_unreadable`); it reads the directory and nothing else. `streamZipMember(range, name, opts)` yields the member's decompressed bytes as chunks for `method` stored or deflate, checks the CRC-32 at the end (`why: "member_crc_mismatch"` as the last result, never silently), reads no byte outside the member's compressed span, and refuses another method `unsupported_method` before reading. A member name is matched exactly; a name that is not unique in the directory is `ambiguous_member`. Test: a sparse ZIP64 fixture with a member over 4 GiB lists its true sizes; the second of 3 members streams reading only its span; a flipped byte ends `member_crc_mismatch`; a bzip2 member is `unsupported_method`. Control: a member streams identically from a whole file.
- **R3** (T53; N1259; K1485 row 9, K4403 (5), DEC-408) **`reduce(row, definition)` drops every column that must not be kept before any other code sees the row.** It returns `{kept}`, a map of only the columns whose definition `keep` is true, in the definition's order. K5499: of a home address only the street lines are removed; ZIP, map coordinates and city stay as the source gives them (a nine-digit ZIP stays nine; the search term `zip5` is its first five digits). A column the definition does not list, and a `home_address` or `phone` column, are never in `kept`. `droppedColumns(header, definition)` returns the names of the header's columns that were dropped, as `{name, why}` with `why` `contact_role` (a `home_address` or `phone` role) or `unlisted` (not in the definition), names only, never a value. A definition that keeps a contact role is refused (`jurisdictions` R128) and, if handed here, `reduce` answers `{ok: false, why: "definition_keeps_contact"}` and returns no row. Test (DEC-408's import test): a fixture whose `home_address`, `phone` and an unlisted column hold sentinel values reduces to rows with no sentinel anywhere in the serialised output; `droppedColumns` names the three and holds no value; a nine-digit ZIP, a city and a map coordinate stay as the source gives them. Control: kept values are unchanged.
- **R4** (T53; N1259; K1485, K1493, DEC-408) **`contactShape(text, streetTypes)` finds a phone number or street address typed into a free-text cell, and a kept cell that has one is withheld.** `contactShape(text)` is pure and answers `{found: boolean, kinds: ["phone"|"address"]}` for North American phone forms (with or without area code in parentheses or dashes, extension forms) and street-address forms (a number, a street word and a type, optional unit), the street types being data passed by the caller from the active layers (`jurisdictions`' federal layer holds the USPS street suffixes; `build/layers.md` rule 1; K5577), never words held in this module's code; it never throws and answers `{found: false}` for a non-string. `reduce` applies it to every kept cell whose role is `other`, `name`, `organization` or `form` (free text), replaces a cell where it is found with `{withheld: "contact_shape"}`, keeps the rest of the row, and counts withheld cells per piece (`withheld_cells`). It is not applied to `amount`, `date`, `filer_id` or the id roles. Test: sentinels "(555) 010-7731" and "4012 Sentinel Ave, Apt 6" in a free-text cell are withheld and counted, the row's other cells intact; 40 non-contact strings (amounts, dates, ids, "Measure 5500") are not. Control: a cell with no shape is unchanged.
- **R5** (T53; N1259; K4403 (2), (7)) **`indexTerms(kept, definition)` gives the search terms of a row, one rule for the filter and the store.** It returns `{name_tokens, org_tokens, amount, date, filer_id, form, place}`: tokens are case-folded, diacritics stripped, punctuation removed, split on spaces and commas, suffixes and honorifics (Jr, Sr, II, III, Mr, Mrs, Dr) kept as tokens, order not significant; `amount` is `{units, scale, currency}` an exact decimal in the definition's currency, from a text that reads as one amount (parentheses or a leading minus a negative), else null with the cell undetermined; `date` is a civil date by the column's `date_format`, else null; `filer_id` and `form` trimmed exact; `place` `{city, state, zip5}` case-folded (`zip5`: the first five digits). A cell that cannot be read as its role is `undetermined` in the answer's `undetermined` list, never coerced. No phonetic, nickname or fuzzy matching in this release. Test: "MARTINEZ, ROSA M" and "Rosa Martinez" give equal token sets; "(1,000.00)" is -1000.00; "13/45/2026" is undetermined; "Bob" does not match "Robert". Control: a clean row has no `undetermined`.
- **R6** (T53; N1259; K4403 (2); K1484) **The filter is a closed set of criteria; `validateFilter` and `matches` are its one meaning.** A filter is `{names?, organizations?, amount?: {min?, max?}, date?: {from?, to?}, filer_ids?, forms?, places?: [{city?, state?, zip5?}], licence_numbers?, docket_numbers?}`; the empty filter `{}` is the whole register. `validateFilter(filter, definition, view)` answers `{ok: true, filter}` or `{ok: false, code, field}`, refusing `FILTER_CRITERION_UNKNOWN`; `FILTER_ROLE_ABSENT` (a criterion for a role the definition lacks, e.g. an amount where there is no `amount` column); `FILTER_VALUE_INVALID` (a name under 2 characters, a non-decimal amount, `min` above `max`, a non-civil date or `from` after `to`, an id not of the scheme's form per `id-spaces.recognise`); `FILTER_PATTERN_REFUSED` (a `*`, `?`, regular expression or "all filers of X": a wildcard is not a name or a number, K1484); `FILTER_TOO_LARGE` (over 1,000 names or organizations, or 500 ids). `matches(row, filter, definition)` is true when every present criterion holds, a list holding when any item does; a name item holds when all its tokens are in the row's name tokens (R5); an amount or date criterion on a row whose value is undetermined does not hold and the row is counted `undetermined` by the caller; the empty filter matches every row. `filterFingerprint(filter)` is the SHA-256 of the canonical JSON (keys and list items sorted, de-duplicated, names token-normalised). All three are pure and never throw. Test: each refusal by name; "MARTINEZ ROSA" matches "Rosa Martinez" and not "Rosa Martin"; a list of two names holds on either; one filter in two orders has one fingerprint; `{}` matches every row. Control: a filter naming an id in its scheme's form validates.
- **R7** (T53; N1259; K4405 (1), (5); K1484; K4403 (7)) **`autoWatchable(filter)` says whether a filter may be watched without a member's act.** It is true exactly when the filter holds no `names` and no `organizations` (a name or an organization may be a person) and holds at least one other criterion; false for `{}`. It is pure. A filter that is not `autoWatchable` is kept, shown and used by a member's search or re-check, never by an unattended read (K4405 (1)). Test: `{filer_ids}` and `{amount: {min: 500}, places: [{zip5}]}` true; `{names}`, `{organizations, amount}` and `{}` false. Control: without the name it is true.
- **R8** (T53; N1259; K4403 (2)) **`prefillFrom(facts, definition)` offers a filter from what the project already names, and invents nothing.** `facts` is `{subjects: [{kind: "person"|"organization", label}], identifiers: [{scheme, value}], period?: {from, to}}` handed by the caller. It returns `{filter, basis}`: the criteria the register's roles support (a person or organization label to `names` or `organizations` only where the register has a `name` or `organization` role; an identifier whose scheme the register issues to `filer_ids`, `licence_numbers` or `docket_numbers`; a period to `date`), and `basis` the fact each criterion came from; criteria a register cannot apply are left out and listed in `left_out`. A fact of any other kind (an address, a phone, a note) yields nothing.Test: two subjects, a filer id of the register's scheme and a period prefill those four; an `address` fact and a note's text prefill nothing; a register with no `amount` role never receives an amount. Control: no facts give `{}`.
- **R9** (T53; N1259; K4403 (5); K4405) **`createReducer({definition, piece, filter, header, sha256})` (`sha256`: `createResumableSha256`) turns the original stream into the reduced copy as it passes, recording the original's fingerprint.** `write(chunk)` takes the piece's decompressed bytes and returns the reduced bytes ready to store (possibly empty); `end()` returns the rest and `{ok, original: {sha256, bytes, covers}, reduced: {sha256, bytes, rows_in, rows_out, rows_undetermined, kept_columns, dropped_columns, withheld_cells}, filter_fingerprint}`. `original.sha256` is the SHA-256 of every byte passed in (as served), `bytes` their count, and `covers` states what they are (`whole_file`, or `member:<name>` of an archive the caller read by range): a fingerprint is never claimed for bytes not read. The reduced copy is delimited text in one canonical form (UTF-8, comma, LF, quotes only where needed): the header row of the kept columns plus a first column `src_row` holding each row's 1-based number in the original piece, then the rows of `matches` in source order; unmatched rows are not written. Equal input, definition and filter give equal reduced bytes, whatever the chunking; the original is held in no more than two windows. Test: a fixture split at every position gives one digest; `original.sha256` equals an independent hash; a filter matching 2 of 10 rows gives 2 rows each with its `src_row`, `rows_in` 10, `rows_out` 2; sentinel contact columns never appear in the reduced bytes; `covers` is `member:<name>` for a member read by range. Control: the empty filter gives every row.
- **R10** (T53; N1259; K4403 (2)) **`estimate(sample, totals)` gives a row count from a sample and says it is an estimate.** `sample` is `{bytes, rows, spread}` (head, middle and tail of a piece, or its first window), `totals` `{bytes}` (the piece's uncompressed size when known). It answers `{rows: {value, low, high, basis: "estimated"}, bytes_per_row}`; `low` and `high` come from the spread of the sampled windows' bytes-per-row. It never answers a count and never `basis: "counted"`; with no sample it answers `{rows: {value: null, basis: "not_stated"}}`. Test: uniform rows give an estimate within 10% of the true count; a fixture whose tail rows are 5 times longer has the true count inside the interval; no input gives `counted`. Control: a sample of the whole file gives `low` equal to `high`.

## Private

### Uses

- `record-grammar`: `createSha256` (its R20) and `createResumableSha256` (its R64), for R9's fingerprint of the original and R6's `filterFingerprint`.
- `civil-time`: `isCalendarDate`, for a column's `date_format` (R1, R5) and R6's civil dates.
- `id-spaces`: `recognise(view, space, value)`, for an id in a filter (R6).
- `ooxml`: `decodeText` only (R1's encodings). Its zip services refuse a member over `MEMBER_MAX`, an archive over `ARCHIVE_TOTAL_MAX` (256 MiB each) or 10,000 entries (its R30), which the measured files exceed, so R2 has its own directory reader and inflate (K5530 F4; `ooxml` is unchanged).
- `csv-reader`: `createRecordWalk`, the piecewise walk, promoted to `csv-reader`'s Provides (its R28; K5530 F4).
- `runtime-limits`: `boundOf` (the bounds this module quotes; `READ_BOUNDS` is not applied to its stream, K5530 F4, `runtime-limits` R47).
- `test-support`: `sheetgen` (builds CSV and TSV, not pipe) and `zipChunks64`, for tests.
- `setup-words`: `word`, `localize` (the words rule: a sentence people read is read by key; K3930, K3943, K3949).
- Not `jurisdictions`: a definition and a view are arguments.

### Invariants

- **R11** (T53; N1259; K4403 (2)) **Invariants of the module.** (a) Pure: no store, network, clock or randomness (the SHA-256 and date reading are arguments or earlier modules'). (b) Never throws: every failure is a returned `{ok: false, why}` or a yielded `{error}`. (c) It knows no register by name and no place: definitions and views are arguments (`layers.md` rule 1); its tests use the test profile's definitions and at least one that is not Oakland's. (d) It calls no AI and uses no `ai-*` module. (e) It assigns no meaning: a row is cells and terms, never a finding, score, rank or judgment of a person. Test: the module's imports include no `ai-*`, `agent-*` or `skills` module; each public function returns for `null`, `undefined`, a number and an empty buffer without throwing; no output has a key `score`, `rank` or `suspect`. Control: the imports are those in Uses.
