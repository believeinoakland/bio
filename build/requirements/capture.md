## Public

### Purpose

Brings material into the record with its provenance: fetches a document from its public address (directly, through a Google Drive export, from a web archive, or rendered as a visitor saw it), hashes and stores it as it arrives, records the fetch as a receipt, profiles what it is, captures a page's supporting files, and returns the provenance document a caller promotes. It also keeps what capture learns about sources and sites (reachability, site assets, links), and the doorbell by which anyone may hand the group material. It writes no bundle: no intake path writes live state.

### Provides

Terms. The **document address** is what the record identifies the document by; the **retrieval locator** is what was actually fetched (they differ for an archive replay and a Drive export). A **public locator** is `https:` on a named public host (`isPublicHttpsLocator`: no bare IP, no `localhost`, no credentials, a dotted host). The **caller class** and whether the caller is a member session are the control plane's stamps. Every refusal names a `reason`; one with a catalogue row carries its `check` and `translation`.

**acquire(body, {cls, member}) → answer** The one act that fetches and files. `body`: `locator`, optional `via` (`"archive.org"`), `address` (archive arm), `render`, `subresources`, `continue`, `authority`, `file`, `matchedSweep`. Success answers `{ok: true, existed, existed_undetermined?, document, parts?, subresources?, snapshot?, files?, subresources_skipped?, note}`.

*Who may acquire, and from where*
- **R1** A `daemon`-class caller is refused `NOT_PERMITTED` except on the archive arm and on the capture-request arm (Open for Bob 1); the archive arm is refused `NOT_PERMITTED` to any class but admin, probe and daemon.
- **R2** The fetched address must be a public locator, else `BAD_LOCATOR`. Nothing a caller sends can supply a hop, a retrieval locator for the archive arm, an export address, an export format or a producer: every such fact is derived by this call at the moment it fetches.
- **R3** **The archive arm** (`via: "archive.org"`). The body names the document's own public `address` (else `BAD_ADDRESS`). The arm runs only when the address is fallback-eligible (R8), else `NOT_ELIGIBLE` with the reachability; it queries the CDX index through the host governor (`web.archive.org` held to 24 requests a minute), chooses a row by `capture-sources.selectCapture`, and fetches its replay. `ARCHIVE_UNREACHABLE`, `ARCHIVE_REFUSED`, `HOST_COOLING_OFF`, and a selection refusal with every row considered, are answered by name. The document address is the CDX `original`; the chain gains the archive's hop built from the CDX record this call fetched. `archiveLookup({address})` decides and reports the same without capturing.
- **R4** **The Drive arm** (a Google Drive address, per `capture-sources.readDriveAddress`). A body carrying any hop fact (`export_address`, `export_format`, `producer`, …) is refused `DRIVE_HOP_FACT_SUPPLIED` (C-48.1) whatever its address. A folder, a file of undetermined kind and an unrecognised shape are refused `DRIVE_FOLDER_NOT_A_DOCUMENT`, `DRIVE_KIND_UNDETERMINED`, `DRIVE_SHAPE_UNRECOGNISED` (C-48.2–C-48.4). A harvestable address is fetched at its composed OpenDocument export; a non-2xx export is `DRIVE_EXPORT_UNREACHABLE` (C-48.6), an HTML content type is `DRIVE_EXPORT_IS_THE_SHELL` (C-48.5, body never read), and bytes detected as HTML are `DRIVE_EXPORT_BYTES_ARE_THE_SHELL` (C-48.7). The application shell is never filed in the document's place. The document address is the Drive link as given; the chain gains Google's hop (`capture-sources.driveHop`, `bound: false`).
- **R5** **The render arm** (`render` present and not `false`). Any value but `true` is `RENDER_FLAG_MALFORMED` (C-83.1); with the archive arm, a Drive export or `continue` it is `RENDER_ARM_CONFLICT` (C-83.2); with no renderer bound, `RENDER_NO_RENDERER` (C-83.3, 501). Before any fetch it asks the host governor for the page's host (`RENDER_HOST_COOLING_OFF`, C-83.5) and the render allowance (R39): over the concurrency cap it is `RENDER_AT_CAPACITY` (C-83.8, `waiting`, nothing reserved); with the day's allowance committed or unreadable, `RENDER_DEFERRED` (C-83.4). Served bytes that are not a single-part HTML page are `RENDER_NOT_A_PAGE` (C-83.6) and the reservation is released at no charge; a failed or oversized render is `RENDER_FAILED` (C-83.7) and nothing is filed. Every other path releases the reservation with the render's elapsed time.
- **R6** A filed render is a pair: the rendered document is the primary (`capture.method` `rendered`, its own digest), the served shell is held beside it under its own digest as `snapshots/<name>.shell.html`, and the document carries `pair`, `render` (`capture-sources.renderBlock`, each subresource body the renderer handed over hashed by this instance and kept) and `shell`. Content authority is `capture-sources.renderedAuthority`'s.
- **R41** A render asks for the locale `capture-sources.renderLocaleFor` answers for R17's view; timezone stays UTC. *(not yet met: K48 — every render asks "en-US")*
- **R42** `acquire` does not read the document: its answer carries no `reading` or `text_units`. Reading from the stored capture is `extraction`'s (K49). *(not yet met: K49 — index.mjs 9250–9932 reads it inside acquire today)*

*The fetch*
- **R7** Every outbound fetch goes through the host governor: admitted (after any wait it names) or refused `HOST_COOLING_OFF` (429, with `retry_in_ms`); each response's status and `Retry-After` is reported to it. The user agent names CivicOS, the instance and the purpose (`acquire`), or the member-browser agent a request delegated.
- **R8** Each attempt at a document address is recorded as `success`, `source_refused`, `fetch_failed` or `governed`. A governed refusal is counted apart and never as a failure. The address is fallback-eligible after 3 consecutive failures, or after at least 2 failures with the first 14 or more days old; the three figures are instance settings with those defaults. `sourceReachability({addressNorm})` answers the counts, the thresholds, eligibility and a basis sentence, `known: false` for an address never attempted.
- **R9** The body is hashed as it arrives and stored content-addressed in parts of 8 MiB, each part under its own SHA-256 with its checksum. Refusals: a thrown fetch is `FETCH_FAILED` (502); a non-2xx status is `SOURCE_REFUSED` with the status; no body is `NO_BODY`; more than 256 MiB is `TOO_LARGE` (413) and the stream is cancelled; zero bytes is `EMPTY`. A single part whose digest differs from the running hash is `HASH_DISAGREEMENT` (500).
- **R10** `existed`: for one part, whether that object was held before this call wrote it; for several, `true` exactly when `provenance.registerHolds` finds the whole digest registered under an existing bundle, otherwise `null` with `existed_undetermined` saying what was and was not asked and how many parts were already held. Several parts never answer `false`.
- **R11** A continuation (`continue: <session>`) resumes that session's outstanding supporting files against the session's own primary; the primary is not fetched again. *(not yet met: K49 — the primary is fetched again and its new digest used, while the answer says it never is)*

*What is recorded*
- **R12** Every filed capture writes one acquisition receipt (`provenance.recordReceipt`) under the document address (the CDX `original`, the Drive link as given, or for a direct fetch the address it resolved to after redirects), `via` (`archive.org` for the archive arm, else `direct`) and the retrieval locator, whatever its content type and whether or not its supporting files were captured. A failed receipt write does not fail the capture.
- **R13** `document.transport` records the requested and resolved addresses, whether it redirected, the status, every response header, and `peer_address: null` with the reason it is unavailable.
- **R14** Content authority: a non-empty `authority` in the body is `authority_state: "determined"` with a dated basis naming the asserting member or caller; none is `"undetermined"` with a dated basis, never refused. An undetermined capture enqueues one `authority-undetermined` event (`taskEnqueue`, one per capture digest; subject the fetched locator, or the Drive link for a Drive export); a failed enqueue does not fail the capture.
- **R15** `taskEnqueue({kind, captureSha, subject, locator, at})` accepts only a known kind (`BAD_KIND`) and a 64-hex digest (`BAD_CAPTURE_SHA`), bounds the subject and locator (2,000 characters), dedupes on (kind, digest) (`deduped: true`), and arms the scheduler's drain.
- **R16** The document carries `provenance_chain`, first hop this instance (`who`: instance name, CivicOS and version; asserts "these bytes were served for <locator> at <retrieved>", or for a render what the render produced and, when its wait timed out, that they are not asserted to be the whole page; `bound: false`; `via`), then the archive or Drive hop; `capture` (`method`, `grade` R18, `actor_class` — `member` for a member session, `session` for a probe, `daemon` otherwise — `sha256`, `encoding: "binary"`, `bytes`, `content_type`, and `transport` unless rendered; `authority: "Internet Archive"` on the archive arm); `parts` (file, digest, size) when multi-part; `origin` (`named_request`, or `sweep` with `matched_sweep` and the deeming actor); `attestation_attempts: []`; and `file` `snapshots/<name>`, `locator`, `retrieved` (this instance's clock, to the second).
- **R17** `document.profile` is `docprofile`'s over what was fetched: `identify` over the headers, document address, content type and (single-part, textual, within bound) the stored bytes read back; `doctypeFor` with the combined view of the instance's active jurisdiction profiles (`jurisdictions.combine` of record-core's `jurisdiction_profiles`); `profileRecord`, the content type key, label, version, confidence, signals and contract; the normalisation rules and boundary; `format` from `format-registry.detectFormat` over the bytes (the first KiB read back when not already read), else the declared type with the absence stated; and `digests`. *(not yet met: N3, N10 — no view is passed)*
- **R18** `capture.grade` is `provenance.captureGrade`'s rule: `EARNED_CAPTURE_CEILING` for a direct fetch, `ARCHIVE_CAPTURE_GRADE` for the archive arm, each read from its one definition. *(not yet met: D-698 — the archive letter is typed `"C"` in `index.mjs`)*

*Supporting files (`subresources: true`)*
- **R19** Only a single-part HTML primary of at most 8 MiB is walked; otherwise `subresources_skipped` names `TOO_LARGE_TO_PARSE`, `NOT_HTML`, `PRIMARY_UNREADABLE`, `NO_SUCH_SESSION` or `SESSION_UNREADABLE`, and the capture is unaffected. The walk is `subresources.captureSubresources` with: `isPublicHttpsLocator` as the fence; the stored object as `put`/`readBack`; the platform ceiling from `captureLimit` unless a probe is due; the host's site assets as `siteLookup`; and a `fetchOne` that returns `HOST_COOLING_OFF` for a host the governor is cooling, waits a 50–250 ms jittered stagger (an instance setting), reports every outcome to the governor, and answers a non-2xx as `SOURCE_REFUSED`. Afterwards it records the observed ceiling (`recordCaptureLimit`), the links (`recordLinks`), the site observations (`recordSiteAssets`), and the compute measurement; parks a session when anything is outstanding and drops it when complete. The answer carries `subresources`, `snapshot` (manifest and companion digests, counts, `complete`, `outstanding`, `platform`, `reuse`, `part_fetch_spread`, `compute`, and a `continuation` naming the session) and `files`. A failed bookkeeping write never fails the capture.

*Co-attestation*
- **R20** An acquisition requests, wherever the source permits, a trusted timestamp over the capture digest and a co-archive of the locator at capture time, recording each attempt and its outcome in `attestation_attempts`. *(not yet met: Intake §3, Open for Bob 2 — acquire records `[]`; `provenance.attest` is a separate act and its co-archive is opt-in)*
- Errors: every refusal above is an answer, never a throw; a store or bookkeeping write that fails is stated or ignored as said, never turned into a failed capture.

**putCapture(sha256, bytes) / getCapture(sha256, range?)** The evidence store by digest (`op=capture`).
- **R21** `sha256` must be 64 lowercase hex (`requiredArgument`). A put whose body hashes to anything else is `INTEGRITY`, naming both digests; an object already held answers `existed: true` and is not rewritten; otherwise it is stored with its checksum. A get answers the bytes (206 for a range) with `x-capture-sha256`, an optional sanitised download name, or `NOT_FOUND`. With no evidence store configured, both answer the storage-absent refusal.

**Capture sessions: saveCaptureSession({session, locator, primarySha, primaryFile, base, state, ttlMs}), loadCaptureSession({session}), dropCaptureSession({session})**
- **R22** A session holds a walk's resume state for `ttlMs` (default one hour); load answers `found: false` with a note for an unknown or expired session; drop removes it.

**captureLimit(runtime) / recordCaptureLimit({runtime, observed})**
- **R23** The platform's outbound-request ceiling is learned by being refused, never declared: `recordCaptureLimit` with an observed ceiling records it (a different value replaces it and keeps the old one as `previous` with the instant it moved); with none, it counts one more run that was not refused and records nothing about where the ceiling is. `captureLimit` answers the ceiling, and `probeDue` when none is recorded or 25 runs have passed unrefused since the last observation, so a ceiling is re-probed rather than only ever learned downward.

**Site assets: siteAssets({host, addresses}), recordSiteAssets({host, primarySha, observations}), reusedParts(bundleId), recordReuseVerdicts({bundleId, verdicts}), reuseVerdicts({bundleId | sourceCapture})**
- **R24** `siteAssets` answers each asset the host was seen serving, with `documents`, the number of distinct document addresses (receipts) whose captures referenced it, and `documents_undetermined` for referencing captures with no receipt (CAP-13).
- **R25** `recordSiteAssets` adds an unseen asset; for one fetched with bytes different from those held it updates the asset, counts the change, and appends a dated `posthoc` `changed` reuse verdict for every capture that reused the old bytes, naming them; a fetched asset's `last_fetched_by` names the capture whose fetch it was, and a reuse never moves it (CAP-14). A reused part's source is the reusing capture's own record, `undetermined` when it names none.
- **R26** `recordReuseVerdicts` appends dated `ratify`-phase verdicts, never overwriting one; `reuseVerdicts` lists them newest first.

**Links: recordLinks({sourceCapture, sourceBundle, capturedAt, links}), linksTo({address_norm}), resolveLinks({sourceCapture}), recordLinkVerdict(…)**
- **R27** `recordLinks` replaces a capture's outbound links, one row per (link, normalised citation), each with its raw and normalised address, fragment, partition and origin. `linksTo` answers every capture linking to an address and the elements cited. `recordLinkVerdict` appends a dated verdict for (source capture, address), never overwriting one, and answers the current verdict, the history and whether it changed. `resolveLinks` gives each `deferred` link, against the target's direct receipts only, a verdict: `contemporaneous` when one capture of the target was seen more than once on both sides of the source's retrieval; `superseded` when every capture of the target postdates it; otherwise `undetermined`, with the basis (bracketing captures differ, one capture at the source's own instant, all captures predate it, or a self-reference) and the target's capture and home. `offsite` when the record holds no capture of the target; `anchor`, `intra` and `refused` pass through. Undetermined is the resting state, stated as such.
- **R28** A link is classified as site chrome only when it is contained in a chrome region AND recurs across two or more distinct pages of the host; a link in a chrome region seen on one page only reads chrome `undetermined`, never lost; the classification is recorded with its basis and date and is always reclassifiable, never a deletion. *(not yet met: D-340, D-702 — the `chrome` column is never set)*
- **R29** Site chrome is a derived table, per host, regenerable by scan: each host's navigation observed with a fingerprint and date, and a per-host read of what navigation changed between captures. *(not yet met: D-340)*

**The render allowance: renderAdmit({allowanceMs, reserveMs, cap, at}) → `{state: "admitted", slot, …}` | `{state: "waiting", …}` | `{state: "deferred", …}`; renderSpend({ms, releaseMs, slot, at}) → day's account**
- **R39** Admission, in order: with `cap` set, slots past their expiry are reclaimed, and with `cap` or more running the answer is `waiting` with nothing reserved or counted; a reservation that is not positive is `deferred` (an unreserved admission is refused); when the day's spent plus reserved plus this reservation exceeds the allowance it is `deferred`, and the day's deferral count rises; otherwise the reservation is added to the day, a slot is taken that expires after the reservation, and the answer is `admitted` with its slot. Days are UTC dates.
- **R40** `renderSpend` frees the slot, adds the reported elapsed time (rounded up) to the day, and releases at most the reservation still held (never below zero); with no elapsed time reported it adds nothing and leaves the reservation charged.
- Errors: never throws.

**The doorbell: knock({contentB64 | contentText, note, contact}), inboxList(status), inboxGet(knockId), inboxResolve({knockId, status, by})**
- **R30** Anyone may knock, with no account. The envelope over the byte cap plus 4 KiB is `KNOCK_ENVELOPE_TOO_LARGE` (C-85.3); no content is a required-argument refusal; bad base64 likewise; empty content is `KNOCK_EMPTY` (C-85.5); content over 8 MiB (with an evidence store) or 64 KiB (without, stored inline) is `KNOCK_PAYLOAD_TOO_LARGE` (C-85.4).
- **R31** At most 12 knocks per source (a fingerprint of the connecting address, never the address) and 300 per instance in any 10 minutes, estimated by a two-bucket sliding window (`prev × (1 − elapsed/W) + cur`, refused at `≥ limit`) counted in the same transaction as the write: `RATE_IP` (C-85.1), `RATE_GLOBAL` (C-85.2), each with `stated`, the published bound composed from the same constants. A store that does not answer is reported as silence, never as a rate refusal.
- **R32** An accepted knock writes one inbox row (`KNOCK-<date>-<8 hex>`, digest, size, `note` to 2,000 characters, `contact` to 300, received time, status `new`) and, with an evidence store, the bytes under `bio/inbox/<digest>`; nothing else changes. Only a signed-in member lists, reads and resolves knocks (`pulled`, `discarded` or back to `new`, else `BAD_STATUS`), recorded with who and when. A knock is not a capture and not a bundle.

### Invariants

- **R33** No intake path writes live state: `acquire` returns a provenance document and writes no bundle, no register row and no file of the record; the caller promotes (CAPTURE-FIDELITY, "The doctrine's constraints").
- **R34** The raw bytes as served are the primary evidence: hashed at receipt, stored under their own digest, never rewritten; every derived artifact (render companion, manifest) is separate and says so.
- **R35** A provenance fact a caller can hand in is one a caller can invent: every address, hop, export fact, grade and receipt in the answer is derived by this call from what it fetched (R2).
- **R36** Fetching is policy-governed, never caller-governed: every outbound request is to a public locator, through the host governor, under a user agent naming the instance and purpose (Intake §4).
- **R37** Each refusal carries its catalogue row: C-48.1–C-48.7, C-83.1–C-83.8, C-85.1–C-85.5, C-28.13 (Open for Bob 1).
- **R38** No place is named in this module's behaviour or outward text; local vocabulary reaches profiling only through the profile view (R17).

### Suggestions

- **The op handlers move here** (layers ruling 2); `control-plane` keeps routing, authentication and the envelope. `acquire` becomes a service the handler calls, which is also what the capture-request arm needs.
- **What stays out.** `projectLinks` writes `refs` (connections, K23). `driveShells`, the monitor tick, `#fireArchiveFallback` and the `#conditions*` readers are monitoring's and the scheduler's; they call `acquire`. The tasks inbox (`taskDrain`, `taskList`, `taskForward`, `taskResolve`, `#routeTask`) routes by project ownership and `refs`, so it goes to a later module that drains this module's event queue (K49); this module keeps only the event queue R15 writes, and the render allowance (R39–R40).
- **Observation rows.** `recordReuseVerdicts` writes observation-log rows (§4.1 row 3); a listener like provenance's `onReceipt` (its R47) serves it.
- **The compute measurement** (`recordruntime`, `runtime_observations`) belongs to whichever module owns that table; until then legacy-store.
- Tests: each C-48, C-83 and C-85 refusal gets a negative control; R10, R12 and R35 get over-strictness arms (a plain capture unchanged byte for byte). Built work for D-340 and D-702 is on `land/worker/D-340` and `D-702` (snapshot branch), and for D-698 on `land/worker/D-698`, judged at the job.
