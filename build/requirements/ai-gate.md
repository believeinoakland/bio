# ai-gate — requirements

**Status** · New module, BOB's (K5457; placed at layer 6 after `agent-worker`, FOLD-AI §2.9); every requirement marked not yet met (T53). Written from `build/plan/lane-ai-design/draft-ai-gate.md` (AI-DESIGN #3 and #4: AI6 A, K5480; AI7 B, K5481; AI8, K5482; the health signal of AI12, K5487), Bob's pass marks waiting on the first measuring run (AD13, K5475). The Gate 1 suite is never called "conformance" (an existing module). Its container is `agent-runner`; the issuer service and the private key are `ai-issuer`'s; the signed catalogue and its lifecycle states are `ai-catalogue`'s. The gate record is an extended `ai-runs` R75 record that this module computes and `ai-runs` writes and hands to `run-rules` as `held.gateRecords` (FOLD-AI §2.4), so no edge points upward.

## Public

### Purpose

Decides, with evidence, whether an AI at a host can do Civicsmith's work, part by part. It holds the Gate 1 suite (a versioned, signed item bank; the scorer; the threshold table), runs it through the same `agent-model` interface and adapters production uses against a stub plane with synthetic cases, scores it with the plane's own checks plus the suite's own, and yields a verdict per (catalogue entry, part): passes, passes with limits, not suitable. It plans the tiers (connect, screen, full, characterize), the characterization procedures, the cost estimate and ceiling shown before a run, the canaries that watch drift on Civicsmith's own accounts, the results bundle's format and its verification, and the rows the results library publishes. Its judgement is code against known answers; a person's reading is a separate labelled note.

### Provides

Terms. A **part** is one of the catalogue's six ids `ask`, `draft`, `read`, `transcribe`, `run`, `account` (`ai-catalogue` R14), the six gate parts, `run-rules` `GATE_PART_OF`'s values; a **role** is the canon's name for people (FIND, PURSUE, EXTRACT, CHECK, ask, draft, read, transcribe, standing question). An **entry** is a catalogue entry as `ai-catalogue` states it. An **item** is one scored case of the bank. A **run** is one execution of a plan against one entry. A **stub plane** is the in-memory synthetic plane an item runs on. A **challenge** is `{challenge_id, nonce, bank_version, selection_seed, issued_at, expires_at}` issued by `ai-issuer` (its R9). A **tier** is `T0`, `T1`, `T2` or `T3`. Every function is pure unless it says otherwise: it holds no state, writes nothing, never throws (a broken precondition answers `{ok: false, code}`). Parameters named in capitals live in one exported table, `GATE_PARAMS`, in the suite version; **none carries a number that is Bob's** (AD13).

**The suite and its versions**
- **R1** *(not yet met: T53)* (T53; SR5, SR90, SR91; AIR11) Four independent versions, `bank`, `scorer`, `thresholds` and `image` (the digest the release names), are each a string; `suiteVersions()` returns all four and every result, record and bundle names all four. The bank and the threshold table are signed data in their own `signatures` namespace (`NS_GATE_SUITE`, a new compiled constant distinct from every other) delivered on `ai-catalogue`'s channel; `loadSuite(signed, allowedKeys)` answers `ok: true` only when the signature verifies in that namespace. Test: a good signed bank loads; a bank signed in `NS_RELEASE_NOTICE`, one altered by a byte and one with no signature each answer `ok: false` with distinct codes. Control: a new bank version leaves every stored verdict unchanged (R39).
- **R2** *(not yet met: T53)* (T53; SR1, SR12, SR92) The bank has a **public part** (item id, group, parts, tiers, content kind, token profile for the estimate, the fixture a model is shown) and a **private part** (expected answers, held by Civicsmith only). `publicBank()` carries no key of the private part. Test: every item of `publicBank()` has no `answer`, `expected` or `states` key; control: the private bank has them for every answer-bound item.
- **R3** *(not yet met: T53)* (T53; SR4) Every fixture is Civicsmith-authored and marked `synthetic: true`; `loadSuite` refuses an item without the mark, and a lint over fixtures finds no id of the shape a team's records, members or addresses take. Test: an item missing the mark is refused by name; control: a marked item loads.
- **R4** *(not yet met: T53)* (T53; SR2, §4) `GROUPS` names ten item groups, `G0` Connect and identity, `G1` Tool use, `G2` Structured output, `G3` Grounding, `G4` Restraint, `G5` Reading, `G6` Consistency, `G7` Honest absence, `G8` Efficiency, `G9` Civic work not refused. Each item names exactly one group, and each group names its scorer: a plane check (module and R id) or `suite-only`. Test: every item's group is in `GROUPS`; every scorer named exists as a callable. Control: a group with a scorer that does not exist fails the load.
- **R5** *(not yet met: T53)* (T53; SR6, SR11, SR13) `GROUP_NEEDS` is the table of which groups each part needs (● needed for the verdict, ○ measured only), part by part, versioned with the bank; `G9` is needed for every part that reads records. `rolesOf(part)` maps a part to the roles people read; the record keeps the part name. A part whose mode does not run end to end (`investigate`, `extract`, `agent-harness` R2) is tested at the level the harness can run and carries `partial_coverage: true`. Test: `G9` is `needed` for `ask`, `draft`, `read`, `run` and `account`, and not for `transcribe`; every part id has a row. Control: a part without a row answers `ok: false`.
- **R6** *(not yet met: T53)* (T53; SR32, SR80) `selectItems(publicBank, selection_seed, tier, parts)` returns the item ids and their order as a deterministic function of the bank version, the challenge's `selection_seed`, the tier and the parts, so the container and the verifier compute the same list. Test: equal inputs give equal lists; a changed seed gives a different list; the list of a tier is a subset of the next tier's pool. Control: no input other than those four changes the list.
- **R7** *(not yet met: T53)* (T53; SR92) An item carries `uses`; `rotate(bank, usage, {ROTATE_AFTER_USES})` returns the bank with items used that many times in verified bundles moved to `retired_items` (kept for re-scoring, never selected again). Test: an item at the limit is not selected; its stored results still re-score. Control: one below the limit stays selectable.

**Running**
- **R8** *(not yet met: T53)* (T53; SR2, BR32) A run calls a model only through `agent-model`'s `turn` by entry id, with the adapter and host profile production would use; `ai-gate` holds no HTTP client, no provider URL, no model string. Test: a scan of `src/` finds no `fetch(`, no `https://` and no provider name; a fake provider reached through `agent-model` serves a run. Control: a planted `fetch(` in a fixture file fails the scan.
- **R9** *(not yet met: T53)* (T53; SR2) Each item runs on a **stub plane** built from the item's synthetic case and the real harness, worker loop and checks (`agent-harness`, `agent-worker`), reachable by nothing outside the process, holding no real record, answering project A only where the item says so. `runItem` returns `{outcome, exchange, stub_log}`; the stub log is every op the model's tool calls reached. Test: an item whose model calls an op outside the part's table finds the call in `stub_log` refused; no network call is made while it runs. Control: a model calling an allowed op finds it answered.
- **R10** *(not yet met: T53)* (T53; SR32, SR30) `planRun({entry, tiers, parts, nonce, suiteVersions, declared})` fixes before the first call the item list, its order, the repeats `N` per item and the sampling settings (temperature or its absence, effort, maximum output, seed where the entry offers one, as the role uses them in production). A run is never extended or cut short to reach a result except by R50's ceiling or R18's early stop, both recorded. Test: equal inputs give an identical plan; a run that ends early records the reason. Control: no function of the module adds an item after `planRun`.
- **R11** *(not yet met: T53)* (T53; SR30; BOB's counts) `GATE_PARAMS.REPEATS` is `{T1, T2, consistency, canary}`, four named parameters (Suggestions). Every repeat runs on a fresh session: no shared cache key, no provider-held state. Test: no two repeats of an item share a session key; control: an item with repeats 1 has one exchange.
- **R12** *(not yet met: T53)* (T53; SR20, SR23, SR9) An item's outcome is `pass`, `fail`, `not_run` or `not_applicable`. `not_run` is for the infrastructure: after `agent-model`'s bounded retries (BR26) a rate limit, spend or quota cap, overload, timeout or revoked key remains, or R50's ceiling stops the run; a `not_run` item leaves the denominator and counts in CH3. `fail` is the model's: a malformed answer, a failed check, a refusal where the item does not expect one. `not_applicable` is for an item needing a capability the entry declares it lacks; the part's verdict then names the limit (R36). A served-identity or host-pin mismatch is neither: it is recorded as `identity_mismatch`, counted apart, and stops the run (R18). Test: one injected error per BR26 class yields the outcome this line gives. Control: a malformed answer is a `fail`, never `not_run`.
- **R13** *(not yet met: T53)* (T53; SR34) Tiers run in order `T0`, `T1`, `T2`, `T3`; `nextTier(result)` allows the next only when the one before completed and its early-stop rules (R18) did not fire. Test: a T0 stop allows no T1; a completed T1 allows T2. Control: `T3` is refused for an entry that passed no part at T2 (R17).
- **R14** *(not yet met: T53)* (T53; SR34, G0) **T0 Connect**: one call per capability the entry declares (`tools`, `schema_output`, `image_input`, `streaming`), the two-turn tool round trip ("echo", then "done", generalising `agent-worker` R111 to every adapter) and, through an aggregator, a pinned request; served identity and host pin checked (BR12) and the capability answers compared with the catalogue's. Test: a fake provider serving another model than the entry fails T0 with `identity_mismatch`; control: a faithful one completes.
- **R15** *(not yet met: T53)* (T53; SR34) **T1 Screen**: one pass of every group at short context, repeats `REPEATS.T1`, a cheap first look per role; no long-context or image probe for a role that does not need it. Test: the T1 plan has repeats `REPEATS.T1` for every item; control: T2 has `REPEATS.T2`.
- **R16** *(not yet met: T53)* (T53; SR34) **T2 Full**: all groups with repeats (R11), long-context and image probes only for parts that need them (R5); this tier yields the verdict. Test: a plan for `ask` holds no transcription item; control: a plan for `transcribe` does.
- **R17** *(not yet met: T53)* (T53; SR34, SR70, SR71) **T3 Characterize**: the timed and repeated runs of R41–R48, spread over days. It runs only on an entry that passed at least one part at T2 (`passes` or `passes_with_limits`). A single run of a team yields a snapshot labelled with its window. Test: an entry with only `not_suitable` verdicts is refused T3 by name. Control: one part passed admits it.
- **R18** *(not yet met: T53)* (T53; SR35) Early stops, each recorded with its reason: at T0 a wrong served identity, a host pin not honoured, or no tool calling where every listed role needs it stops the run; at T1 a group failing every item stops the probes that depend on it (no long-context probe for a model that cannot follow the report shape). Test: a model failing every G2 item stops the G5 probes of the same part. Control: a model passing one G2 item does not.
- **R19** *(not yet met: T53)* (T53; SR34; AIR12) `connectCheck(account, entry)` runs T0 only, in a team's copy, for an entry the catalogue lists: it uses the public T0 items (no challenge, no answers), writes no verdict, makes no bundle and answers `{connected, identity_ok, capability_mismatches}`. Test: it calls no item outside T0 and its result carries no `verdict` key. Control: the same call for an unlisted entry answers `ok: false` (an unlisted plan goes through R20 and the container).
- **R20** *(not yet met: T53)* (T53; AIR12; SR60) A **declared plan** for an entry the catalogue does not list is `{provider, host, model, plan, scope_declared, terms_page?, price?, route}`; `checkDeclared` refuses a host that is not a DNS name over `https`, a wildcard, Civicsmith's issuer, or (unless `route` is `machine`) an address or a private name. Such an endpoint reaches the assistant only after a release lists it (AIR12); until then it reaches `agent-model.turn` only as a declared entry with `test_flow: true` (`agent-model` R42). Test: `host: "10.0.0.5"` is refused on the `cloudflare` route and accepted on `machine`; control: a public DNS name is accepted on both.

**Scoring and verdicts**
- **R31** *(not yet met: T53)* (T53; SR21, SR22) `scoreItem({item, exchange, stub_log, scorerVersion})` is a pure function: the same input gives a byte-identical result, and a new scorer re-scores stored exchanges with no model call. Civicsmith's own runs and bundles use this one scorer. Test: score twice, compare; re-score with a stub scorer v2 and find no call to `agent-model`. Control: a different `exchange` gives a different result.
- **R32** *(not yet met: T53)* (T53; SR21) Checks that need no expected answer (shape, citation resolution, allow-list, schema validity) are **answer-free**; `scoreAnswerFree(item, exchange, stub_log)` runs without the private bank, so the container can show **preliminary** figures labelled so. Answer-bound checks need the private part and run on Civicsmith's side only. Test: `scoreAnswerFree` runs with the private bank removed and its result carries `preliminary: true`; control: an answer-bound check called without it answers `ok: false`.
- **R33** *(not yet met: T53)* (T53; SR24, SR31) `groupFigures(outcomes)` returns per group and part `{k, n, wilson_low, wilson_high, not_run}` with the Wilson interval at `GATE_PARAMS.CI_LEVEL`; no function returns a bare percentage. Test: `{k: 0, n: 5}` and `{k: 5, n: 5}` give known intervals; control: `not_run` items are outside `n`.
- **R34** *(not yet met: T53)* (T53; SR7, AD13) `GATE_THRESHOLDS` is a signed table keyed (group, part) giving `floor` and `FLOOR_COMPARES` (`rate` or `lower`); it ships empty and no number appears in code. With no table, or no floor for a needed group, every verdict is `not_yet_rated`, shown with its figures, counts and intervals. Test: with an empty table a complete run yields `not_yet_rated` for every part and figures for every group; control: a table with floors yields a verdict. Bob sets the floors after measurement (AD13).
- **R35** *(not yet met: T53)* (T53; SR6, SR25) `partVerdict({entry, part, figures, thresholds, caps})` answers `passes` when every needed group meets its floor, `passes_with_limits` when it does with at least one limit named (R36), `not_suitable` otherwise, `not_yet_rated` per R34, plus `partial_coverage` (R5). A part's verdict is never one score for the model: `verdictsFor(entry)` lists a verdict for each part. Test: a stub failing only G4 yields `not_suitable` for `ask` and `passes` for `transcribe`; control: a stub passing everything yields `passes`.
- **R36** *(not yet met: T53)* (T53; SR6) A limit is `{kind, value}` with `kind` from a closed list in the suite version (`context_depth`, `no_image_input`, `no_streaming`, `no_parallel_tools`, `output_cap`); it is derived from `not_applicable` outcomes and from R45's effective window, never typed by a person. Test: an entry lacking image input yields `no_image_input` for `read` and none for `run`; control: a full-capability entry yields none.
- **R37** *(not yet met: T53)* (T53; SR10; D14, D11; BOB's shape) `gateRecord({entry_id, part, verdict, limits, partial_coverage, figures, suiteVersions, tier, run_ref, grade, source, at})` returns the extended test-bar record (the entry's `gate[part]` in `ai-catalogue` R14 is this record) that `ai-runs` R75 writes and `run-rules` R19/R29 read per entry, with `set`, `set_version`, `false_alarm_rate` and `graded_by` kept where Civicsmith's set was run (R38). Test: the record names entry, part and all four versions; control: a record without an entry id is refused.
- **R38** *(not yet met: T53)* (T53; SR12, SR24) Civicsmith's own runs use Civicsmith's set (the frozen matters of `run-rules` R19, scored as today with the false-alarm rate) **and** the synthetic bank; runs of a bundle use the synthetic bank only, since Civicsmith's set travels inside every copy with its answers. `itemSources(runKind)` answers which. Test: `bundle` answers bank only; `civicsmith` answers both; control: a bundle selection never holds a matter of the set.
- **R39** *(not yet met: T53)* (T53; SR91; AIR13) A new bank or scorer never rewrites a stored verdict; an entry tested under an older version reads `tested_on: <bank version>` until Civicsmith's schedule re-runs it. Test: re-rate a stored figure set under a new table and find no call; control: the old verdict record is unchanged.

**Cost estimate and ceiling**
