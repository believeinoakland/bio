## Public

### Purpose

The record store's assembly and the world its tests ask. It builds every module of the record store on one Durable Object's storage, in the modules' order; migrates them before any request; composes their registrations and ops maps into the one route map; passes every store request through `store-door`'s frame; and publishes `storeWorld()`, the real store with a pinned clock, a real claim, and a copy for each test. It imports no platform module, so it runs in plain node; `plane` hosts it as the Durable Object class and the Worker's entry.

### Provides

Terms. The **assembled store** is what `assembleStore` answers (R1). The **owner map** is the arms of the ops whose owners export a service and no ops map (R86). A **world** is what `storeWorld()` answers (R90); `store-request` adds the door, the sign-ins and the recipes over it. The store's request from a page's is made by `store-request`'s `innerRequest` (K5052 (1)). To **compose** a module is to build it on the object's storage in R2's order (its place in `build/modules.json`), run its migration as R3 says, declare its tables to purge through `record-core`, start it so its registrations are held before the first request, hand it the instances it reads (one instance per host) and spread its ops map, if it has one, into R6's route map, so its ops reach their handlers through `control-plane`'s door.

- **R1** *(not yet met: T51)* (was `plane` R1 and R2, in part) `assembleStore(ctx, env, {deliver})` builds every module of the record store on one Durable Object's storage and answers the assembled store `{routes, dispatch, namespace, nowMs, read}` (the route map R6, `dispatch` R7, `namespace` R4, `nowMs` R5, `read` R8). `ctx` is the object's state as the runtime hands it (the surface R90 lists); `env` is its bindings (`STORE`, `CAPTURES`, `ACCOUNT_SEAL_SECRET`, `RECEIPT_SIGNING_KEY`, `INSTANCE_NAME`, `AGENT_WORKER`, `FILE_SCANNER`, `CAPTURE_CREDENTIALS_KEY`, `OWN_HOSTS`, `BIO_NOW_MS`), each optional and read where it is used; `deliver`, optional, is `control-plane`'s owed-render delivery (`deliverOwedRender`, `control-plane` R124), handed to the owed-work ledger: absent, a ledger row that needs it stays owed (R67).
