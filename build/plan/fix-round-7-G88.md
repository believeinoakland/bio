A plain text has no `sheets`, and reading-pipeline's own `classify()` (R42, one classification per read) never goes through `readText` or `classificationView`, so it passes the full 12 MB to every `detect`. G48 bounded the 17 MiB CSV path only. R38 bounded this classification by HEAP only (no second copy), never by time. A sample is wrong for a text (a type may rest on any page), so the fix is a yield, not a bound.
