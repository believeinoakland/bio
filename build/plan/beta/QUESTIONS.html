Files the beta reads · from the FILES lane

You ruled that the beta must take in and read any kind of file of any reasonable size (K4628), and that the list be studied closely before it is final (K4632). This is that study. Under the Public Records Act, the city must hand over a record in any electronic form it holds it in, so members will get mailbox exports, databases and map files, not only PDFs. Whatever list we pick, someone will eventually bring a file that isn't on it.

F1FILES · N1266asked 27 Oct

How long should the list of readable file types be?

  • A1 · Exactly what you ruled (about 20 types)PDF, Word, Excel, CSV, PowerPoint, the OpenDocument files, text, RTF, web pages, JSON, XML, six image types, email files and ZIP, TAR, GZ, 7z. Smallest build. Any type you didn't name has to be asked for later.
  • RecommendedA2 · What you ruled, plus about 15 cheap related typesCalendar invites, contact cards, MBOX mailboxes, saved web pages, vector images, map files, Excel and Word files with macros (the macros are never run), meeting caption files, data exports. Almost all use a reader we already have, or are plain text. A member who holds one isn't told "not read" when the fix is a day's work.
  • A3 · A2, plus the costly typesOutlook archives, Access databases, WordPerfect, Apple's office files, CAD drawings. Not now: nothing yet shows members hold these files (see F3).

These stay refused by name whatever you choose: RAR archives (your ruling), and programs, installers and disk images (for safety).

A1–A8 · the alpha's live walks27 Oct · DEC-457 to DEC-464 (UX design stream)

Answered in the UX design stream and recorded there. Each is now a requirement for the beta's lanes:

  • A1 "as recommended": a question can name its subject when it is opened, and a member may change it later, with the reason kept.
  • A2 "as recommended": a government's fiscal year comes from the place's records or a member's statement. Money never prints "*".
  • A3 "as recommended": a handed-in file's source link is shown to listed members only.
  • A4 "B, but only drop metadata is necessary": a safe picture is redrawn from a photo, dropping only the metadata safety requires.
  • A5 "as recommended": the two Capture measures are named separately. Signing lists every ungraded passage.
  • A6 "as recommended": one queue item per member for new signing keys.
  • A7 "as recommended": pickers show this project's documents first.
  • A8 "B, with the proper grade assigned…": a typed page can be cited at once, marked "not yet checked". A second member's check raises its grade by one step.
