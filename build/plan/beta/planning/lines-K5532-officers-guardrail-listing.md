## 4. For BOB (technical)

1. **`registers` R46 `query` and R130's number-only rule.** R46 says `officersLookup({query, ...})` without saying what a query is. R130 (jurisdictions) forbids a template with a name hole; K1484 reads "a watch is by a number". Recommendation: `query` is a company number of the `company` scheme, composed through the template (section 1.1); a name search over officers is out of this release. If a lookup by company name or officer name is wanted, that is a policy question for Bob (a search for a person, K1484/G1), not a technical one: not decided here.

Either way the stream path to `streamRegister` stays the job's to state (K5532).

Recommendation: while `rate_limits` is absent `keyedFetch` refuses `RATE_HELD`-style with reason `LIMITS_NOT_MEASURED` and sends nothing, so the officers service stays off until a job measures it; a one-sentence amendment to R131 (not drafted here, as it touches `acquisition`).
