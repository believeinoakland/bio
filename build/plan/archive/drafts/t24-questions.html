T24 Questions for Bob

Your UX rulings DEC-112 to DEC-116 (PR #7) owe new requirements. I have drafted them for the next tranche. Six points are yours: four about the architecture and two about what a ruling means. Each has my recommendation. Answer each with "agreed" or your own choice. Nothing is built until PR #7 is on main, which I merge at T23's close, as PR #6 was.

New parts of the product (architecture)
Q1

The docket gets its own module

DEC-116's docket is the signed list beside each published case, with its shelves, the manager's To-dos, outside responses, standing and withdrawal. It is too large for any existing part. Publication would pass the size limit, and the others serve a different purpose.

Recommend: a new module, docket, in the Publication layer, right after publication, so the public case page can show a withdrawn edition's stamp and the docket's latest entry.
Q2

The open case checker gets its own module

DEC-112 asks for a checker anyone can run outside CivicOS to verify a case file. It has to run the same publication checks ratification runs.

Recommend: a new module, case-checker, in the Publication layer, right after ratification, built as a standalone program from the same code CivicOS uses. Then CivicOS and outsiders check a case the same way.
Q3

Importing another group's case gets its own module

DEC-112 covers importing a case into a read-only project and confirming each finding by recreating it. Accepting that work (DEC-96) is allowed only once it has been recreated.

Recommend: a new module, case-import, right after the checker, holding import, recreation and acceptance. If acceptance grows, I split it out later.

Other choices: two modules now (import, then acceptance), or a new layer for work between groups.

Q4

Where a device keeps assistant transcripts (DEC-113)

The litigation hold stops a device from deleting transcripts of held projects. No part of the product stores transcripts on a device yet. The browser only reads one.

Recommend: build the server side now: the hold's project list, the heavier release, the "is this project held?" answer, and the wipe refused during a hold. The device side waits until device storage is built, in a new module named for it then. That is also when you set how long a transcript is kept (DEC-61 calls for a time limit but none is ruled yet).
What a ruling means
Q5

Does a hold also block removing a single item?

DEC-113 refuses "the operator's wipe of the real record" while a hold stands. The operator can also purge one bundle, for example after a removal is ordered.

  • Refusing it too is safer against destroying evidence.
  • But it would block an ordered removal until the hold is released.
Recommend: refuse a single-item purge of material in a held project too. If a removal is ordered, the hold's release (the heavier act) is the path, and it is on the record.
Q6

Whose attestation stands behind material that can't be published (DEC-112)

For material that cannot go in the case file, DEC-112 lists "the attesting member's, the project's and the group's" attestations. The member's attestation exists today. No record holds a project's or a group's attestation of a source.

Recommend: the project's and the group's attestations are their signatures on the case itself: the owner's signature and the group's key. Those already exist and already cover everything the case contains.

Other choice: a new attestation act at project and group level, which a new ruling would have to define.

Already decided by me (recorded in K1134; no answer needed)
  • The case-file format's open specification lives with the case format's own requirements, with a readable version published beside each format version.
  • "Material that cannot travel whole" means bytes or text this copy does not hold. Copyright stays the group's judgement, in the warning, as DEC-112 says.
  • An imported case is judged against the importing group's default bar. Later editions of the same case sit beside the earlier ones in the same read-only project.
  • Releasing a hold is its own act, graded as the heaviest. A release form lists only the projects the releaser can see, so a hidden project is never revealed. A device that cannot check keeps the transcript.
  • "Matters" replaces "subject" in every member-facing text. The start-and-send sketch and the two filing panels bind the Action redesign.
  • The public case page and publication are measured before their jobs start, and split first if either would pass the size limit.
