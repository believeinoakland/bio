Part 1 · One pass for a mechanical change

P7, a new paragraph at its end

A mechanical change is one pass. When the same change, needing no judgment, must be made across many modules (a word replaced; a sentence moved to the word table and read by its key; a test made to read a sentence from the word table instead of copying it; an import or call re-pointed to a module's own declaration), it is made in one pass by a worker in BOB's session while no job runs, not by one job per module. Before the pass is committed, every module it touched has its tests run in one full run, beside the checks and the regenerated artifacts. A module where the change needs a judgment is left out of the pass and gets its own job. The pass is recorded in a ruling naming every module it touched.

Why: this is the method that worked for "team" (K3811). Without it, every such change costs one job per module, which is how wording became fragile.

P8, its first sentence

The unit of work is the module job, except a mechanical pass (P7).

Mechanics, a new §5.10

5.10 A mechanical pass (P7, P8). (1) BOB states the change as a rule a script or a worker applies the same way in every module, and the list of modules, read from the checks' findings, never from a hand-made list. (2) No job is running. (3) One worker (sonnet, medium) applies it on the tranche branch, leaving out any module where the rule needs a judgment, and lists those. (4) The whole module test suite (module-tests.mjs), checks/run.mjs and the generated artifacts run once; every red is fixed in the pass or the module is left out. (5) BOB reads the diff's summary and every line the worker marked uncertain, then commits. (6) A ruling names the rule, every module touched, every module left out (each gets an entry in the running plan) and the test result.

Open none while an archived plan reads CLOSING and main is behind it (§5.7), nor while checks/run.mjs's words check reports any finding (P12, P7).

Mechanics §8, a sixth check

6. Words: no module's own code holds a sentence people read (it reads each by key from the word table); no test copies such a sentence; every key a module reads exists in the word table; no test hand-lists another module's operations, error codes or words (P7; bio K3366, K3810, K3268). It runs in every job's checks before COMPLETE and at every layer close, so a regression fails at once.

Mechanics §8, check 4 (format), a new clause
