#### 1. The overlay: checks every walker makes on every screen

Each check is made as the member as well as the administrator wherever the two differ. Record the screen, the check number and the words as rendered; a state that cannot be forced is recorded as "not forced", not as a pass.

1. **Undetermined.** One component, one fixed mark, a mandatory "because..." line, the same everywhere; never an error, never a zero. [surfaceRules statesToDesign.undetermined; DEC-86; IC section U, IC:654-682]
2. **Withheld.** A hidden object leaves its own treatment and one fixed sentence stating incompleteness, never identity, title, state or count. Test with the second account on every screen with a hidden object; downstream lists (dependents, cited-by) say something was withheld. [surfaceRules statesToDesign.withheld; DEC-86; DEC-36; openQuestions[22]]
3. **The other neighbours: Unrated, Nobody looked, Refused.** Each has its own visibly different treatment and fixed sentence pattern; none shares a look with Undetermined (the old UI used one badge for undetermined and "no grade yet"); none is dressed as an error; "Nobody looked" differs from looked-and-absent. Find each on at least three screens. [openQuestions[5], DEC-86, DEC-82; IC:654-682]
4. **Ordinary states.** Force an empty list ("Nothing here"), a slow read ("Still loading"), a failed read ("Could not read this, because...": a screen that cannot tell none from could-not-read must say could-not-read). [DEC-98; DEC-94; openQuestions[14]; IC:654-682]
