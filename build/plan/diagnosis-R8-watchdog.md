Reproduced: `watch()` mid-run answers `rearmed false, why null` (both reproductions). ## Finding 3: `stale` false in all 214 samples (its definition against K4566)
1. **Root cause (certain, by definition).** `health()` (:709-716): `owed` = the earliest wake already come; `since = max(owed, last_run)`; `stale = since !== null && now - since > 2 * HEALTH_CYCLE_MS` (600 s). So a stall must last ten minutes **with no firing completed in them**; a completed firing resets the clock even when the oldest wake has been owed for 691 s; and a firing in progress is not looked at (`running_since` is ignored, :711-715), the same stance as R29's "a busy object is not a dead one". The worst `last_run` gap walker A saw (551 s) is below 600 s, and every long run did complete, so `stale` could not turn true. R28 (`scheduler.md`) defines exactly this ("owed for two cycles with no completed firing in them"), tested as defined (`spent.test.mjs:103-125`). The definition measures a dead alarm; the product's need (K4565, K4566) includes owed work that does not move. A reading row owed 11 minutes is not "stale" to it.
2. **Why the tests missed it.** The test asserts the definition on a double; no test confronts it with a stall made of firings that complete, which is the platform's actual shape; and the walker's expectation was never written down as a number (the brief's 9-minute stall). K4565 also says a stall is never shown to administrators or members, so `stale` on `owedwork` is a detection signal for the process, not a screen; nobody owns "what threshold means stalled".
3. **Failing-first.** `bio-plane/test/m/scheduler/r8-stale.test.mjs`: with the walker's numbers, `oldest_overdue` 691 s old, `last_run` 551 s old, `running_since` null: `health().stale === true`; and with `running_since` 400 s old and a due row 400 s old: `stale === true`; controls: owed 60 s, firing 30 s ago: false; nothing owed: false. The threshold is BOB's detail (recorded in `rulings.md`); the test pins whatever it is. Through the door, in the seam file `bio-plane/test/m/control-plane/t51-round8-seam.test.mjs`: the founder's `op=owedwork` answers `stale: true` for a row held that long (built with the platform-shaped double, not a hand-written answer).
4. **Platform check: N** for the definition (arithmetic on instants), **L** for the shape that makes it true (Finding 1 test (a) with a 40 s scanner). Owning module: **scheduler** (`health`, R28's definition); provider **plane** (the route, K4565's rule on who sees it).
