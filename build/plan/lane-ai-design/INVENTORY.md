## §2 The AI roles

"Needs" is read from the tool and bound definitions, not from a design. Common to every model path: tool use with custom tools and a named final tool (am R6); tool-result channel is the only carrier of record text (am R12, aw R61); a per-call `usage` (input, output, cache read/write tokens, cost) with `null` allowed (am R5); a refusal stop (am R3); resumable by the plane, not the model (canon §4). Where it runs: **worker** = `agent-worker` Cloudflare Worker (service binding from the plane); **runner** = `agent-runner` container (disabled, ar R35) or remote Claude Code session (`REMOTE`, ar R36 unmet); **plane** = `bio-plane` (checks, writes, grants, counting).
