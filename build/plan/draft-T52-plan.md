## 4. Requirement lines (all BOB's, P18; written on the tranche branch before each layer's START)

**New module `register-readers` (L1).** Purpose: reads the bytes of a public register file into rows, filters them by a team's criteria, and writes the reduced copy that is stored, without touching a record. Provides: `readRows`, `validateFilter`, `matches`, `prefillFrom`, `reduce`, `reducedCopy`, `estimate`. Rules: drops `keep: false` columns before any other code sees a row; never throws; bounded memory; holds no store or clock; knows no place (definitions are profile data).

**New module `registers` (L5).** Purpose: holds the public registers a team has imported, whole or in part, mechanically; lists the known registers and teams' own; plans an import (filter, delta, time estimate); searches the held rows; cites a row; compares imports; keeps the filter for change-watching; holds no fact, score or judgment about anyone, and never uses an AI. Provides (names BOB's): `registerList`, `registerDefine`, `registerPlan`, `importStart/Status/Pause/Stop`, `importTick`, `searchRows`, `rowOf`, `citeRow`, `compare`, `saveFilter/forgetFilter/filtersOf`, `tombstone`. Rules: member's act only; gated/fee-bearing `member_act_required`; no query text written anywhere; every FEC answer carries the use limit; officers `REGISTER_NOT_IN_ALPHA`.

**Changed lines** (each a one-to-three-line amendment): jurisdictions R4, R52 + new register definitions; connection-grammar R10, R14 (and explore R3's ordering line); acquisition R10 (streaming arm), R36 (free keyed service on the alarm), new arrival reduction and probe; extraction R20; content R7, R12, R21, R52; connections R65 + `named_in`; money R16 + `moneyByParty`; explore R2, R3, R5, R10, R14, R21, R23, R27, R28; case-grammar (K1483 register clause); corpus-export R9; case-checker R13; case-disclosures R24; monitoring R30; following R9, R12, R13 + `register-query`; scheduler consumer; affordances R59-R60, R68; notice-producers findings; the screens' lines after the design commit; **K1483** amended for registers by Bob's K4403 4.
