  - Requirements: reading-pipeline R40, pdf-reader R43.
- **I2 Progress.** Every tick that answers `more: true` moves the cursor forward; the number of ticks is at most `pages` plus 2.
  - Requirements: reading-pipeline, plane R77.
- **I3 Never silent.** Every page that is not read whole carries a named reason in the reading and in the member's statement. `completeness` is "whole" only when the cursor is at the end, nothing is owed, and no page is unread for a reason other than "has no text".
  - Requirements: extraction R91, K4571.
- **I4 Memory.** The child running the real plane at 128 MB, with the held bytes inside it, stays alive, and its peak is within E4's budget.
  - Requirements: pdf-reader R41, reading-pipeline R36, superseded by E4.
- **I5 Work per tick.** Every tick's counted work is within E1's budget, and its longest synchronous stretch is within E2's (a count of operators between yields, not a time).
  - Requirements: reading-pipeline R40, plane R93.
- **I6 Pieces equal whole.** The stored reading of a PDF read in pieces equals its whole read, field for field, the fields of F2.
  - Requirements: reading-pipeline R40, R12.
- **I7 A refusal is stated, final and finite.** Every bound in §2.2 answers its named statement once. Nothing is owed forever, no kill is retried more than E6's 3 times, and no row stays "being read" after the last tick.
  - Requirements: plane R77, extraction R82.
- **I8 State loss is harmless.** Losing the open document, or restarting the object, between any two ticks gives the same reading and units; only the tick's work differs.
  - Requirement: reading-pipeline R40.
- **I9 Every path owes what it leaves.** Upload, promote, press, ledger, `op=pdfstructure` and `pagetranscribe` all owe pages and ranges a cap left.
  - Requirements: reading-pipeline R37, extraction.
- **I10 Search finds the last line.** The last line of the last page (and a first and a middle line) is found by `op=search` and is citable.
  - Requirements: extraction R22, R90.
- **I11 The reading pages to its end.** `op=reading` with `next` reaches the last page with no answer over 1 MiB; the Document screen's Next page reaches it.
  - Requirements: extraction R93, screens-inquiry.
- **I12 Stored values bounded.** No stored value exceeds 1 MiB, and none exceeds the platform's value bound.
  - Requirement: extraction R96.
- **I13 Contention.** While the corpus file's ticks run, cheap reads through the door wait under 500 ms at p95.
  - Requirement: plane R93.
- **I14 Same bytes, same answer.** Two runs of the same file give byte-identical readings and units.
  - Requirements: pdf-reader R24, reading-pipeline.

SCAN invariants (the family's "always"; each case above is judged against them):

### 4.4 The invariants (the "always", stated once; each corpus file is judged against all of them)

The invariants name the module whose requirements carry them; BOB writes the wording into those requirements (§6). PDF #1's I1-I14 hold for scanned PDFs; these are the scan family's, with the ones it shares noted.
- **SI1 Every page once, and what is left is owed.** Every page of a scan is OCR'd exactly once or stated unread with a named reason; any page a cap leaves is owed on **every** path (upload, promote, press, ledger, `pagetranscribe`, `pdfstructure`); `ocr_left` is read by every caller. *(reading-pipeline R37, extraction R82; PDF #1's I9.)*
- **SI2 Never silent.** `completeness` is "whole" only when nothing is owed and no page is unread for a reason other than "has no text"; a type not read is named; a refusal's own reason reaches the member (S2, S3, S11). *(extraction R91, K4571.)*
- **SI3 Declared before allocated.** Every route judges the header's declared size before any allocation or inflate; a hostile header gets a named 200 refusal in under 1 s and the process stays flat (S5-S7). *(image-codecs, pdf-pixels, image-cover.)*
- **SI4 Memory.** The plane child at 128 MB with the held bytes inside it stays alive and within PDF #1's E4 budget; the OCR member's peak working set (C1) stays within its measured bound for every admitted frame. *(pdf-pixels, ocr-worker, plane.)*
- **SI5 Work.** No member request does OCR or a decode over its K4354 bar; every tick's OCR wait is within C3. *(control-plane, reading-pipeline, plane R93.)*
- **SI6 Progress and finiteness.** Every `ocr` tick that answers `owed` advances or is `final` and stated; a kill is an attempt; a page killed 3 times is stated; no row is "being read" after the last tick. *(plane R77, ocr-worker.)*
- **SI7 Search finds the last line.** A marker word on the last line of the last OCR'd page (and a first and a middle one) is found by `op=search` and is citable with its page. *(extraction R22, R90.)*
- **SI8 Truth.** A page that OCR reads contributes its words at the stated floor (≥ 90 percent on a clean page; the amended floor on a stated-hard one); a page below the legibility floor is stated and is not stored as text (S9, B-S6). *(ocr-worker R25.)*
- **SI9 State loss is harmless.** Restarting the object between any two ticks, or losing the open document, gives the same reading and units. *(reading-pipeline R40; PDF #1's I8.)*
- **SI10 Pieces equal whole.** The OCR text of a scan read in pieces equals the whole read's, and each piece's chain names its pages (S25). *(reading-pipeline R40.)*
- **SI11 Stored values bounded.** No stored value exceeds 1 MiB, and none exceeds the platform's value bound. *(extraction R96.)*
- **SI12 Same bytes, same answer.** Two runs of the same image give the same pixels (`pixels_sha256`) and the same units. *(pdf-pixels R40, image-codecs R8.)*
- **SI13 Honest acts.** No act is offered on a document that it cannot perform; a type not read says so by name once. *(screens-inquiry, extraction.)*
- **SI14 Contention.** While a scan's ticks run, cheap reads through the door wait under 500 ms at p95. *(plane R93; PDF #1's I13.)*

DOCS invariants (the family's "always"; each case above is judged against them):

### 4.4 The invariants (the "always", stated once; each corpus file is judged against all of them)

I1-I14 are the PDF plan's (every unit once; progress; never silent; memory; work per tick; pieces equal whole; a refusal is stated, final and finite; state loss is harmless; every path owes what it leaves; search finds the last line; the reading pages to its end; stored values bounded; contention; same bytes, same answer), read for *units* (paragraphs, slides, lines, members) instead of pages. The kinds here add:
- **I15 Declared is not allocated.** A bound is on what the read allocates and walks (objects, buffers, tokens), with ArrayBuffers counted; a file whose declared size passes and whose walk would not fit is refused *before* the walk, by name. Requirements: office-readers R12, ooxml R35 (rewritten), reading-pipeline R36.
- **I16 An encoding is named.** Every text read states the encoding it was decoded in; a decode that replaces more than the tolerance is partial with the count; nothing is `U+FFFD` and `failure: null`. Requirements: reading-pipeline R1, R32; docprofile R18.
- **I17 Every part is read or named.** A part of a file that is text is a unit; a part not read is named by kind and count in the reading and in the member's statement; the units of a document are never lost to a bound on something else (cells, links, comments). Requirements: office-readers R11; extraction R91, R97; K4571.
- **I18 Every member is accounted for.** An archive's members are each `filed`, `read`, `refused with a cause`, or `waiting for a named act`; none is `waiting` for ever; an uploaded archive is opened like a fetched one. Requirements: acquisition R38/R40.
- **I19 A copy says what it is.** A visitor view carries its fidelity ("first load, not scrolled"), a failed one carries its detail and its retry class, and a copy that did not render is not filed as the document. Requirements: capture-sources, acquisition R100.
- **I20 A deterministic failure is final, with its reason.** A throw on the file's own bytes, or a refusal by a bound, is never `transient`; a transient failure is retried under R77 until it ends or becomes final with its reason. Requirements: reading-pipeline R37; plane R77.
- **I21 A verdict that was not reached says so.** A file the scanner could not look inside (encrypted, over a limit, unrarred) is never `clean`; the member is told which. Requirements: file-scanner R3; file-safety R51.
- **I22 The statement names the cause.** The sentence for a refusal is the one for its cause, with the figure; "Read it" is offered only where it can succeed. Requirements: reading-pipeline R37; screens-inquiry; setup-words.

Corpus files are judged against I1-I22. Lines in §5 say which are particular to the file.

SHEET invariants (the family's "always"; each case above is judged against them):

### 4.4 The invariants (the "always"; stated once; each corpus file is judged against all of them)

The PDF plan's I1-I14, re-cut for a sheet. Each is a sentence for the module named; **a counted bound, never a time** (R-CLOCK). The corpus and §5.3 refer to them as J-n.

- **J-1 Every row once.** Each data row of the file is in exactly one indexed unit; the header line is the *first line of a block* and never a data row; every unit's extent contains exactly the rows it holds. (reading-pipeline R41, new text)
- **J-2 Progress.** A read finishes in at most ⌈unit text ÷ 2 MiB⌉ + 2 ticks; no tick ends with the cursor unmoved; a failure of any tick is retried, never ends the read as finished. (reading-pipeline R40; plane R77)
- **J-3 Never silent.** `completeness` is `whole` only when every row of the file is in the index; anything cut, held, skipped, undecodable or refused is stated with its **size, its bound and its cause in the cause's own words** (not "undecodable region"). (reading-pipeline R15/R35; extraction R90/R91; K4571, K4630)
- **J-4 Memory.** A reader's retained heap between windows is at most 2× its window plus O(columns); the whole read stays alive in a child at the platform's cap with the held bytes inside it. One cap convention for every format: **the platform's measured idle, written once** (S-38).
- **J-5 Work per tick, by count.** A later tick hands an entry at most 5 MiB; it hands the store at most 5 MiB of ranged reads; every window is followed by a yield; no stored value exceeds 1 MiB. (reading-pipeline R40, csv-reader R20, office R35, odf R-new)
- **J-6 Pieces equal whole.** The cells and the text of a windowed read equal a whole read's, and both equal the generator's truth, field for field. (The oracle is the generator, never the reader's past output: P7.)
- **J-7 A refusal is stated, final and finite.** Past a bound the answer is final, names the size and the bound, and no row remains "being read" after the last tick.
- **J-8 State loss is harmless.** A restart or a store failure between ticks (after any tick) neither loses a row nor ends the read: the read resumes or re-reads, once.
- **J-9 Every path owes what it leaves.** Upload (one part and multipart), the doorbell pull, address `acquire`, the daemon paths, and the no-cursor door read all end `whole` or owed; none ends `whole` with `truncated`.
- **J-10 Search finds the first, a middle and the last row,** by a mark placed in a non-header cell; the hit's extent contains the row; `cellsOf` of that extent contains the cell with the mark equal to the generator's.
- **J-11 Cells keep their place.** The cell at A1-style address *x* of a file is *x*, with empty cells, merged cells (the covered cells keep their columns), rows without `r`, and a styled empty cell not moving a value or the used range; text and cell views agree.
- **J-12 Stored values bounded.** No stored value and no reading row over 1 MiB; **a reading is never replaced by a statement while its text could be indexed** (the ODS cliff); a reading over the guard still has its units.
- **J-13 One table, one sha.** A table declared from the same data, whichever kind (CSV comma or semicolon or tab, XLSX, ODS), whichever path (sheet range, document extent, passage, bytes), whichever window cut, has the same rows, the same columns and the same sha; the header appears once; an empty cell keeps its column; a quote, a tab or a line break in a value is a value.
- **J-14 Money by truth.** An ingest of a generated table writes the facts the truth names, each fact's source row is the sheet row; a percent, a currency mark, a locale separator and a date are read as the table declares them, or stated.
- **J-15 Same data, same answer, in every kind.** A workbook and its CSV, TSV and ODS twin give the same cells and the same searchable words, dates included.
- **J-16 Contention.** While sheet ticks run, twelve cheap reads wait under 500 ms at p95 on workerd (R93), **asserted** for the real reads, not printed.
- **J-17 Encodings.** Every cell whose characters the file's encoding can represent is read: no valid UTF-8 character is `null`; a windows-1252 file is decoded with the encoding stated; an undecodable cell is counted, listed up to 200, and never shifts a column.
